# apps/site — 홈페이지 (`www.easymindmap.org`)

소개·기능·AI 연동·mmd 표준·**지식창고**(공개된 맵 목록)가 사는 곳.
앱(에디터)과 **다른 앱**이다.

```
www.easymindmap.org
├ /                → 이 앱 (소개)
├ /function        → 이 앱 (기능 — 무엇이 있는가)
├ /ai              → 이 앱 (AI 연동 — 사상 · 도구 · 붙이는 두 갈래)
├ /mmd             → 이 앱 (mmd 표준 소개 · 옛 /emm 도 같은 곳)
├ /library         → 이 앱 (지식창고 — 공개된 맵 목록 · `?q=` 로 검색)
├ /site-assets/…   → 이 앱의 번들
├ /p/{id}          → **앱으로 프록시** (퍼블리싱 공개 뷰어)
└ /assets/…        → 그 앱의 번들
```

## 글은 `src/content/` 에 있다 — 화면은 개수를 세지 않는다

| 파일 | 어디에 나오나 |
|---|---|
| `content/features.ts` | 홈의 **특장점 카드**(*왜 좋은가*) |
| `content/functions.ts` | `/function` 의 **기능 묶음**(*무엇이 있는가*) |
| `content/emphasize.tsx` | 본문 구절을 `<b>` 로 감싸는 도우미(데이터에 HTML 을 안 쓰려고) |

항목을 더할 때 **손대는 곳은 그 배열 하나**다. 격자는 3→2→1열로 접히므로
7개가 되어도 그대로 붙는다. `functions.ts` 의 `guide` 는 **근거가 된 사용자
가이드 장**이고 화면에 작게 나온다 — 없는 기능을 적지 않기 위한 장치다.

★ **뷰어를 여기에 복제하지 않는다.** 뷰어는 내보내기 HTML 생성기
(`exportHtml.ts`)와 레이아웃 엔진을 통째로 쓴다. 복제하면 두 벌이
갈라지고, 갈라지면 "앱에서는 멀쩡한데 홈페이지에서는 깨진" 사고가 난다
(실제로 겪었다 — `test-catalog.md` e2e255).

## 돌려 보기

```bash
npm ci
npm run dev            # http://localhost:5174 — API 는 api-dev 를 본다
```

`/p/{id}` 는 dev 서버에 없다(프록시는 nginx 가 한다). 그 화면은 앱에서 본다.

## 홈페이지 아웃라인·지도 실시간 체험

- 왼쪽 아웃라인에서 노드를 추가·수정·삭제하면 오른쪽 지도에 즉시 반영한다.
- 오른쪽 노드를 선택한 뒤 툴바로 추가·수정·삭제할 수 있다. 수정은 해당 아웃라인 입력란으로 이동한다.
- 입력은 브라우저 메모리에만 유지한다. 네트워크 전송, 로컬 저장소, 계정 저장, AI 호출을 하지 않는다.
- 저장·닫기 버튼은 없다. 초기화는 현재 선택한 예시의 원본을 다시 불러온다.
- 다른 페이지로 이동 후 돌아오거나 새로고침·BFCache 복귀 시 기본 질문 예시로 초기화한다. 같은 홈의 해시 구간 이동은 편집을 유지한다.
- 노드 본문은 말줄임하지 않는다. 전체 텍스트를 줄바꿈하고 노드 높이와 지도 크기를 계산한다. 큰 지도는 패널 안에서 가로·세로로 스크롤한다.
- 간단 체험 한도는 80개 노드, 8단계, 노드당 10,000자, 전체 60,000자다. 초과 입력은 자르지 않고 명시적으로 거부한다.
- Enter는 같은 단계 추가(중심에서는 하위 추가), Ctrl+Enter는 하위 추가, Shift+Enter는 줄바꿈이다. IME 조합 중 Enter는 가로채지 않는다.
- 텍스트는 DOM value/textContent로만 반영한다. 사용자의 글을 HTML로 삽입하지 않는다.

### 검증

npm test로 노드 CRUD, 한도, 초기 예시 독립성, 전체 텍스트 보존, 줄바꿈, 레이아웃 회귀 테스트를 실행한다. npm run build도 이 테스트부터 실행한다.
브라우저에서는 실시간 반영, 지도 선택/수정, 예시 전환과 초기화, 페이지 재진입, 모바일 패널 스크롤과 키보드 입력을 확인한다.

## 상단 브랜드 영상: YouTube

- egtron 홈페이지처럼 YouTube 기본 플레이어로 소개 영상을 재생한다. 영상: https://youtu.be/DXDej-QOD0k (egtron 채널, 약 30초).
- 개인정보 보호 강화 모드인 youtube-nocookie.com의 반응형 16:9 iframe을 사용한다. 초기 자동재생·무음 반복 재생·별도의 재생/음소거/자막 버튼은 사용하지 않는다. 영상 중앙의 YouTube 재생 버튼으로 시작한다.
- 플레이어 UI 언어는 홈페이지의 한국어·영어·일본어·중국어에 맞춘다. 내레이션은 한국어이며 자막·번역·화질·전체화면은 YouTube가 제공하는 범위에서 설정한다. 기존 4개 WebVTT가 YouTube에 자동 적용된다고 안내하지 않는다.
- iframe을 lazy load하고 origin referrer를 전달한다. 외부 플레이어가 제한될 때 사용할 YouTube 새 탭 링크를 항상 표시한다.
- 홈이 아닌 안내 페이지에서는 iframe src를 제거해 숨은 재생을 중단한다. 홈으로 돌아오면 자동재생 없이 다시 표시하며 홈 안의 해시 이동은 재생기를 초기화하지 않는다. React 해제 때도 iframe을 비운다.
- 기존 public/hero-media/v3/ MP4·포스터·자막·VOICE-LICENSE.md는 보존한다. 과거 다운로드 링크와 음성 출처는 변경하지 않는다. 앱/API/계정/결제 및 배포 설정은 변경하지 않는다.
- npm test와 npm run build에서 주소·네 언어 템플릿·접근성·반응형·라우트 이동·해제 회귀 검사를 실행한다. 실제 YouTube 재생은 별도 브라우저에서 확인한다.
