# 홈페이지 영상 v3 음성·음악 출처

- 영상: EasyMindMap 자체 제작, 홈페이지 실제 편집 체험 맵 화면 사용.
- 음성: Supertonic 3의 공식 고정 프리셋 Sarah로 생성한 한국어 합성 음성. 실존 인물이나 Typecast 목소리를 복제하지 않았다.
- 생성: 공식 브라우저 데모, 한국어, speed 1.0, 8 steps. 2026-11-02 생성. 음량만 정리하고 말속도·피치는 변경하지 않았다.
- 모델: https://huggingface.co/supertone-oss-archive/supertonic-3
- 모델 라이선스: OpenRAIL-M https://huggingface.co/supertone-oss-archive/supertonic-3/blob/main/LICENSE
- 라이선스 §6: "Licensor claims no rights in the Output You generate using the Model." 이용 제한은 계속 적용된다. 이 홈페이지의 일반적인 소프트웨어 소개에 해당 합성 출력물을 사용한다.
- 배포물은 완성된 영상·자막·이미지이며, 모델·음성 스타일 파일·추론 소프트웨어를 재배포하지 않는다.
- Supertone의 제휴나 제품 추천을 뜻하지 않는다.
- 배경음: 기존 v2의 자체 합성 피아노/패드 아르페지오. 외부 음원 없음.
- v3에는 Typecast·CLOVA·Windows Heami 음원을 사용하지 않았다.
- 캐시 충돌을 막기 위해 v3 경로를 사용한다. 게시된 파일을 수정할 때는 새 버전을 사용한다.
