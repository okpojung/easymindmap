# 모바일 웹 — 폰 브라우저에서 쓰는 EasyMindMap

> 상태: **구현 (2026-10-05, e2e336)** — 사용자 요청 "Mobile 에서도 easymindmap
> web 을 사용할 수 있도록". 앱을 따로 만들지 않고 **같은 웹 앱이 화면 폭과
> 입력 장치에 맞춰 배치를 바꾼다.** 데스크톱 배치는 그대로다.

## 1. 판정 — 한 곳에서 (`src/hooks/useViewport.ts`)

| 판정 | 조건 | 쓰는 곳 |
|---|---|---|
| `useCompact()` | 폭 < 768px | 폭만 보는 것 |
| `useCoarse()` | `pointer: coarse` (손가락) | 누를 자리 크기(40~44px) |
| **`usePhoneLayout()`** | compact **또는** 손가락 + 높이 ≤ 500px(가로로 눕힌 폰) | 상단 막대 · 서랍 · 문서함 카드 · 캔버스 제스처 |

CSS 는 같은 값을 `@media (max-width: 767px)` · `(pointer: coarse)` 로 쓴다
(`components/ui/mobileCss.ts`). 화면마다 제각각 기준을 만들지 않는다 —
같은 폰에서 툴바는 폰 모양, 사이드바는 데스크톱 모양이 되는 일을 막는다.

## 2. 화면별

| 화면 | 폰에서 |
|---|---|
| 상단 막대 | 로고 · 맵 제목(…) · 되돌리기 · AI · 저장(상태 점) · **⋯** · 계정. 나머지(사본 저장·맵 닫기·공유·퍼블리싱·아웃라인·테마·내보내기 등)는 ⋯ 메뉴 — 데스크톱 기능이 전부 닿는다 |
| 레일 + 패널 | 캔버스 위에 **겹쳐 뜨는 서랍**(배경 어둡게, 눌러서 닫기). 캔버스 크기는 바뀌지 않는다. 아래 막대의 패널 단추로 연다 |
| 아웃라인 분할 | 한 화면 + 전환(아래 막대·⋯) |
| 캔버스 | **맵을 열면 Pan 모드로 시작**(2026-10-05 사용자 요청 — 맵을 훑다 노드를 잘못 끌어 옮기지 않게): 어디를 끌어도 화면 이동, 노드는 탭으로 고른다. 맵 도구의 **✋ 단추**(늘 보임)로 끄면 아래처럼 동작한다. 안내문은 켜는 순간 4초만 작게 뜨고 사라진다(주황 테두리·강조된 ✋ 는 남는다). Pan 을 끈 상태: 빈 곳 한 손가락 = 이동, 두 손가락 = 확대(가운데 기준)·이동, 노드 탭 = 선택, 다시 탭(두 번 탭) = 글 편집, **길게 누르기** = 노드 메뉴, 노드에서 시작한 끌기 = 노드 옮기기. 편집 중에는 키보드에 가리지 않게 맵이 비켜 선다 |
| 맵 도구 | 더하기·삭제·**✋ Pan**·맞춤·⋯(노드/중심/보기 묶음) |
| 칸반 | 열 폭 `min(300px, 100vw−56px)` 가로 스크롤(맞춤 정지), 카드는 0.35초 누른 뒤 끌기 |
| 문서함 | 표 대신 **카드 목록**(이름 + 유형·수정일·크기), 카드 탭 = 열기, 줄마다 **⋯ 아래 시트**에 모든 동작. 도움말은 **?** 뒤로 (데스크톱도 ? 단추 — 마우스는 처음에 펼쳐 둔다) |
| 대화상자 | 화면 폭 − 24px, 높이 `100dvh` 안에서 안쪽 스크롤, 안전 영역 |
| 입력칸 | 손가락 기기에서 글자 16px (iOS 가 입력 순간 확대하지 않게) |
| HTML 뷰어(내보내기·`/p/` 공개 링크) | 머리말 두 줄(제목… · 검색 아이콘 · 보기 단추), 한 손가락 이동·핀치 확대, 노트·링크는 아래 시트, 미니맵 기본 꺼짐, 첫 화면은 맵 전체 |

## 3. 문서 전체

- `index.html` 의 viewport: `width=device-width, initial-scale=1, maximum-scale=1,
  viewport-fit=cover`. `maximum-scale=1` 은 노드 편집칸(확대 배율을 따라
  16px 보다 작아질 수 있다)에 iOS 가 입력 순간 페이지를 확대하는 것을 막는다.
  확대는 캔버스가 핀치로 직접 한다.
- 높이는 `100dvh`(주소창이 들고 나도 맞게), 위·아래 막대는 `env(safe-area-inset-*)`.
- 목록 줄 hover 강조는 `(hover: hover)` 에서만 — 터치에서 눌어붙지 않게.
- 마우스 hover 툴팁은 손가락 기기에서 켜지 않는다(누른 뒤 남는 툴팁).

## 4. 알려진 한계

- **실기기(iOS Safari·Android Chrome) 확인 전** — 검증은 Chromium 의 모바일
  흉내(isMobile·hasTouch·CDP 터치)로 했다. 노치·홈 표시줄 여백, 주소창 높이,
  키보드 위 비켜 서기는 실기기에서 한 번 봐야 한다.
- 폰 키보드의 Enter 는 편집을 끝낸다 — 노드 안 줄바꿈은 데스크톱(Shift+Enter)에서.
- 맵 전체가 보이는 첫 화면(20% 안팎)에서는 노드가 작다 — 핀치로 키운 뒤 누른다.
