## 1. 총칙

`[[상호]]`(이하 "회사")는 EasyMindMap 서비스(이하 "서비스")를 제공하면서
이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 등 관계 법령을
준수합니다.

회사는 개인정보 처리방침을 통해 이용자가 제공한 개인정보가 어떤 용도와
방식으로 이용되고 있으며, 개인정보 보호를 위해 어떤 조치가 취해지고 있는지
알려 드립니다.

- **시행일**: `[[YYYY-MM-DD]]`

## 2. 수집하는 개인정보 항목과 수집 방법

### 2.1 이용자가 직접 입력하는 것

| 항목 | 필수/선택 | 언제 |
|---|---|---|
| **이메일 주소** | 필수 | 회원가입 (로그인 아이디로 사용) |
| **비밀번호** | 필수 | 회원가입 (아래 §10 참조 — 복호화 불가능한 형태로 저장) |
| **성명** | 필수 | 회원가입 |
| **휴대전화번호**(국가번호 포함) | 선택 | 회원가입 |
| **표시 이름** | 선택 | 개인 설정 |

> → 근거: `public.users.full_name` · `phone_country` · `phone_number` ·
> `display_name`, `auth.users.email`

**휴대전화번호의 용도**: 본인 확인, 계정 복구, 서비스 중요 공지 발송에
사용합니다. **광고·마케팅에는 사용하지 않으며**, 이용자가 개인 설정에서
언제든 삭제할 수 있습니다.

> ⚠️ **현재는 받아서 보관만 합니다.** 인증하지 않고(`phone_verified_at` 은
> 항상 NULL), 위에 적은 용도로 쓰이는 곳도 아직 없습니다. **예정만 적어 두고
> 실제로 쓰지 않으면 다음 검토에서 같은 지적이 다시 나온다** — 공개까지도
> 쓰지 않기로 정해지면 항목에서 빼는 편이 낫습니다(수집 최소화).

### 2.2 서비스 이용 과정에서 자동으로 생성·수집되는 것

| 항목 | 언제 |
|---|---|
| **접속 IP 주소** | 로그인할 때 · 맵을 저장할 때 |
| **기기 정보**(운영체제·브라우저 종류와 버전) | 위와 같음 |
| **로그인 일시**, 로그인·로그아웃·비밀번호 변경 등 계정 활동 기록 | 인증 처리 과정 |
| **저장 일시**, 저장 횟수 | 맵을 저장할 때 |
| 저장 용량 사용량 | 첨부·문서 저장 시 |

> → 근거: `public.login_events`(client_ip·platform·browser),
> `public.map_document_versions`(client_ip·platform·browser),
> `auth.audit_log_entries`

### 2.3 이용자가 만든 콘텐츠

마인드맵의 제목·노드 텍스트·노트, 업로드한 이미지·첨부 파일과 그 파일명.

이는 이용자의 저작물이며, 회사는 **서비스 제공(저장·불러오기·내보내기)에
필요한 범위에서만** 처리합니다. 회사는 이용자의 맵 내용을 열람·분석하거나
제3자에게 제공하지 않습니다.

> 다만 **서비스 운영·장애 대응을 위해 데이터베이스에 접근할 수 있는 관리자
> 계정이 존재**합니다(관리자 콘솔). 관리자 콘솔에서 볼 수 있는 것은 회원
> 목록·요금제·사용량·로그인 기록이며, **맵의 내용은 콘솔에 표시되지
> 않습니다.**

### 2.4 수집하지 않는 것 (분명히 밝힙니다)

- **주민등록번호·계좌정보 등 고유식별정보를 수집하지 않습니다.**
- **결제 정보를 수집하지 않습니다.** (결제 기능은 아직 제공하지 않습니다.
  도입 시 이 방침을 개정하고 별도로 알립니다.)
- **광고·분석 목적의 제3자 추적 도구(Google Analytics 등)를 사용하지
  않습니다.**

### 2.5 ★ AI 기능과 개인정보 — **회사 서버를 거치지 않습니다**

서비스의 AI 기능은 두 가지 방식으로 동작하며, **어느 쪽도 이용자의 맵
내용이 회사 서버로 전송되지 않습니다.**

| 방식 | 어떻게 동작하나 |
|---|---|
| **① 웹 AI 복사·붙여넣기** | 서비스가 프롬프트를 만들어 주면 이용자가 **직접** 자신의 AI 서비스(ChatGPT·Claude·Gemini 등) 창에 붙여넣고, 답변을 복사해 서비스로 가져옵니다 |
| **② 이용자 API 키 직접 호출** | 이용자가 자신의 API 키를 **자신의 브라우저에** 저장하고, **브라우저가 AI 제공자에게 직접** 요청을 보냅니다 |

②의 경우 **API 키는 이용자의 브라우저에만 저장되며 회사 서버로 전송되지
않습니다.** AI 제공자에게 전달되는 내용은 이용자와 그 AI 제공자 사이의
문제이며, **해당 제공자의 개인정보 처리방침이 적용됩니다.**

> → 근거: `apps/frontend/src/utils/aiProviders.ts` 가 브라우저에서
> `api.anthropic.com` · `api.openai.com` ·
> `generativelanguage.googleapis.com` 을 직접 호출하며, 서버(`apps/api`)에
> AI 관련 모듈이 없다.

## 3. 개인정보의 처리 목적

| 목적 | 쓰이는 항목 |
|---|---|
| 회원 가입·본인 확인·서비스 이용자 식별 | 이메일, 비밀번호, 성명 |
| 서비스 제공(맵 저장·불러오기·내보내기) | 콘텐츠, 저장 용량 |
| **부정 이용 방지와 계정 보안** — 본인이 자신의 접속 기록을 확인하고, 모르는 접속을 발견할 수 있도록 | 접속 IP, 기기 정보, 로그인 일시 |
| 요금제·저장 용량 한도 관리 | 요금제, 사용량 |
| 공지·인증번호 등 필수 안내 메일 발송 | 이메일 |
| 서비스 개선을 위한 통계(개인을 식별하지 않는 형태) | 가입일, 사용량 |

**광고·마케팅 목적으로 이용하지 않습니다.**

## 4. 개인정보의 보유 및 이용 기간

원칙적으로 **회원 탈퇴 시 지체 없이 파기**합니다. 다만 아래는 예외입니다.

| 항목 | 보유 기간 | 근거 |
|---|---|---|
| 회원 정보·콘텐츠 전체 | **탈퇴 즉시 삭제** | 아래 §5 |
| **탈퇴 계정 식별자**(내부 ID 와 탈퇴 시각) | 계속 보관 | 만료 전 인증 토큰으로 계정이 되살아나는 것을 막기 위한 최소 기록. **이메일·성명 등 개인정보를 담지 않습니다** (→ `public.deleted_accounts`) |
| 접속 기록(IP·기기) | **계정당 최근 200건**까지만 보관하고 오래된 것부터 자동 삭제 | → `login-events.service.ts` |
| 이메일 인증번호 | 사용 또는 만료 시 삭제 | → `public.email_verifications` |
| 저장 버전 이력 (자동) | 요금제별 **7일 / 90일 / 1년** — 아래 표 | → [`13a-version-retention.md`](../03-editor-core/history/13a-version-retention.md) |
| 저장 버전 이력 (영구보관) | 이용자가 표시를 해제하거나 맵을 삭제할 때까지 | 이용자가 직접 "남긴다"고 표시한 것이므로 기간 정리에서 제외됩니다 |

**저장 버전 이력의 자동 보관 기간**

| 요금제 | 자동 보관 | 영구보관 상한 |
|---|---|---|
| Free | 7일 | 3개 |
| Basic | 90일 | 20개 |
| Pro | 1년 | 50개 |
| Team | 1년 | 100개 |

맵을 삭제하면 그 맵의 버전 이력도 **함께 삭제**됩니다
(`map_document_versions.map_id … ON DELETE CASCADE`).

> **관계 법령에 따른 보존**: 「통신비밀보호법」에 따른 접속기록 보관 의무
> 등 법령이 정한 경우에는 해당 기간 동안 보관합니다. `[[법률 검토 시
> 구체 항목 확정]]`

## 5. 개인정보의 파기 절차 및 방법

회원 탈퇴 시 다음이 **실제로 삭제**됩니다.

- 로그인 계정(이메일·비밀번호) — 인증 서버에서 삭제
- 회원 정보(성명·휴대전화번호·표시 이름)
- 모든 맵·폴더·저장 버전·첨부 파일과 그 실제 파일
- 접속 기록

전자적 파일은 **복구할 수 없는 방법으로 삭제**합니다(데이터베이스에서
행 삭제 및 저장소에서 파일 삭제).

> → 근거: `account.service.ts` 의 탈퇴 처리 — 인증 서버 계정 삭제 후
> `DELETE FROM public.users` 로 연쇄 삭제(CASCADE)가 돈다.
>
> **탈퇴한 계정으로 다시 가입할 수 있습니다.** 재가입 시에는 새 계정이며,
> 이전 자료는 복구되지 않습니다.

## 6. 개인정보 처리의 위탁

회사는 서비스 제공을 위해 아래 업무를 위탁하고 있습니다.

| 수탁자 | 위탁 업무 | 보유·이용 기간 |
|---|---|---|
| `[[메일 발송 제공자 — 예: Google LLC (Google Workspace SMTP)]]` | 가입 인증번호·비밀번호 재설정 등 **안내 메일 발송** | 위탁계약 종료 시까지 |

> ⚠️ 실제 값은 **관리자 콘솔 → 설정관리 → 메일 발송**의 `SMTP_HOST` 로
> 확인해 채운다.
>
> 수탁자가 국외 사업자인 경우 **국외 이전 사항(이전받는 자·국가·시점·
> 방법·항목)** 을 별도로 고지해야 한다 — `[[법률 검토]]`

**그 밖에 제3자에게 개인정보를 제공하지 않습니다.** 법령에 따라 수사기관
등이 적법한 절차로 요구하는 경우에만 예외로 합니다.

## 7. 정보주체의 권리와 행사 방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

| 권리 | 행사 방법 |
|---|---|
| **열람** — 내 로그인 기록 보기 | 앱 우상단 프로필 → **🕘 로그인 기록** |
| **정정** — 성명·표시 이름 변경 | 앱 우상단 프로필 → 개인 설정 |
| **비밀번호 변경** | 프로필 → 🔑 비밀번호 변경 / 로그인 화면 → 비밀번호를 잊으셨나요? |
| **삭제(탈퇴)** | 프로필 → 회원 탈퇴 |
| 그 밖의 열람·정정·삭제·처리정지 요구 | `[[문의 이메일]]` 로 요청 |

요청은 **지체 없이 조치**하며, 처리 결과를 알려 드립니다.

## 8. 쿠키 및 브라우저 저장소

회사는 **광고·추적 목적의 쿠키를 사용하지 않습니다.** 다만 서비스 동작에
필요한 정보를 이용자의 브라우저에 저장합니다.

| 저장되는 것 | 왜 | 어디에 |
|---|---|---|
| 로그인 세션 정보 | 로그인 유지 | 브라우저 저장소(localStorage) |
| 관리자 콘솔 인증 표 | 관리자 로그인 유지 — **탭을 닫으면 사라집니다** | sessionStorage |
| 작성 중인 맵의 임시 보관본 | 저장 전 작업 내용 보호 | IndexedDB |
| AI API 키(이용자가 입력한 경우) | AI 제공자 직접 호출 — **회사 서버로 전송되지 않습니다** | 브라우저 저장소 |

브라우저 설정에서 저장을 거부할 수 있으나, 그 경우 로그인 유지 등 일부
기능이 동작하지 않습니다.

## 9. 만 14세 미만 아동의 개인정보

**만 14세 미만은 서비스에 가입할 수 없습니다.** 회사는 만 14세 미만
아동의 개인정보를 수집하지 않으며, 수집된 사실이 확인되면 지체 없이
파기합니다.

회원가입 시 **만 14세 이상임을 확인**받습니다.

> → 근거: `SignupForm.tsx` 의 확인란(`signup-age-check`). 체크하지 않으면
> **[가입하기] 가 눌리지 않는다** — 보여주기만 하는 문구가 아니다.
> 처리방침에만 적고 화면에 두지 않으면 제품이 지키지 않는 약속이 된다.

| 조치 | 내용 |

| **비밀번호 보호** | 비밀번호는 **복호화할 수 없는 형태(해시)로 저장**되며, 회사도 원문을 알 수 없습니다. 관리자도 이용자의 비밀번호를 볼 수 없고, 대신 바꿔 줄 수도 없습니다 |
| **전송 구간 암호화** | 모든 통신은 HTTPS 로 암호화됩니다 |
| **접근 권한 최소화** | 이용자는 **자신의 자료만** 조회·수정할 수 있도록 서버가 요청마다 소유자를 확인합니다 |
| **관리자 접근 통제** | 관리자 기능은 **2단계 인증**(비밀번호 + 이메일 인증번호)을 거쳐야 하며, 관리자 명단은 데이터베이스가 아니라 **서버 환경변수**로 관리해 데이터베이스 접근만으로는 관리자가 될 수 없습니다 |
| **가입 시 이메일 확인** | 6자리 인증번호로 실제 사용 가능한 주소인지 확인합니다 |
| **남용 방지** | 요청 횟수 제한(레이트 리밋), 인증번호 시도 횟수·재발송 간격 제한 |
| **접속 기록 보관** | 이용자가 자신의 접속 이력을 직접 확인할 수 있습니다 |
