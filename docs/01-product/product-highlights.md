# EasyMindMap 장점 소개 (제품 하이라이트)

> **이 문서의 용도**: 소개 홈페이지·사용자 설명서 머리말·영업/소개
> 자료에 그대로 옮겨 쓸 수 있는 **일반인 눈높이의 설명 원고**다.
> 기능이 추가·개선될 때마다 여기에 "왜 좋은지"를 사용자 언어로
> 함께 기록한다. (기술 상세는 각 feature 문서, 조작법은 user-guide)

## 한 줄 소개

**"생각을 적는 속도 그대로, 정리는 알아서."** — EasyMindMap은 글로
쓰든(아웃라인·Markdown), 그림으로 그리든(마인드맵), 보드로 옮기든
(Kanban) **같은 내용이 세 가지 모습으로 함께 움직이는** 마인드맵
소프트웨어입니다.

## 왜 EasyMindMap인가 — 5가지 약속

### 1. 쓰던 문서가 그대로 맵이 됩니다

- 메모장·Obsidian·ChatGPT에서 쓰던 **Markdown 문서를 끌어다 놓으면**
  견출·목록·표·코드·체크리스트까지 통째로 마인드맵이 됩니다.
- 반대로 맵을 **Markdown/HTML로 내보내면** 스타일·사진·노트까지 담겨
  다시 불러왔을 때 100% 복원됩니다 (EMM 형식 — 파일은 언제나 표준
  Markdown이라 다른 앱에서도 열립니다).
- 코드·표·체크리스트를 **노드 안에 넣을지, 노트로 붙일지** 불러올 때
  고를 수 있고, 한 노드가 A4 한 장 분량을 넘으면 넘치는 내용을
  자동으로 노트로 옮겨 맵이 문서처럼 비대해지는 것을 막습니다.

### 2. 개발자·실무자의 콘텐츠를 "제대로" 그립니다

- 노드 안에 **코드 블록**(언어 라벨·복사 버튼 포함), **표 격자**,
  **클릭해서 켜고 끄는 체크박스**가 들어갑니다 — 다른 마인드맵처럼
  마커 문자가 그대로 노출되지 않습니다.
- 코드는 작은 노드 안에서 낑낑대며 칠 필요 없이 **팝업 편집기**에서
  언어와 코드를 편하게 쓰고, 연필(✎)을 눌러 언제든 다시 고칩니다.
- 굵게·기울임·취소선·밑줄·형광펜 부분 강조는 라이트/다크 모드
  어디서나 또렷하게 보이도록 색을 따로 관리합니다.

### 3. 화면을 바꿔도 "보던 자리"가 이어집니다

- 큰 맵을 확대해 보다가 **아웃라인 모드로 전환하면, 문서 처음이
  아니라 방금 보던 위치**부터 열립니다 — 노드를 선택해 두었으면 그
  노드로, 아니면 화면 중앙에 가장 가까운 노드로 알아서 찾아갑니다.
- 아웃라인에서 줄을 클릭하면 맵이 그 노드를 가운데로 데려오고,
  맵에서 노드를 클릭하면 아웃라인이 그 줄로 스크롤됩니다.
- 내보낸 **HTML 뷰어도 에디터와 똑같이** 보입니다 — 접기, 검색,
  다크 모드, 노드 안 코드·체크박스까지 1:1로.

### 4. 묻지 않아도 될 때는 묻지 않습니다

- 앱을 막 켜서 아무것도 만지지 않았다면, 새 맵을 만들거나 파일을
  불러올 때 **"현재 맵을 닫을까요?" 확인이 뜨지 않습니다** — 잃을
  것이 있을 때만 묻습니다.
- 맵 전체 레이아웃을 바꾸고 싶을 때 **중심 노드를 찾아갈 필요가
  없습니다** — 아무것도 선택하지 않은 상태에서 레이아웃을 고르면
  맵 전체에 적용됩니다.
- 검색 결과에는 제목 앞에 **[노드]·[태그]·[노트]·[링크] 색 배지**가
  붙어 어디서 일치했는지 한눈에 보입니다.

### 5. AI가 "내 맵의 맥락"으로 일합니다

- 질문 한 줄로 상세한 마인드맵 초안을 만들고(3사 AI 지원), 이미 있는
  맵에서는 **선택한 노드의 조상 경로와 지침을 맥락으로** 그 가지만
  깊게 확장합니다.
- AI가 답을 Markdown으로 쓰기만 하면 맵이 되는 구조(EMM)라, 어떤
  AI를 쓰든 결과가 안정적입니다.

## 세부 배려 모음 ("이런 것까지?")

소개 자료에서 "디테일" 사례로 쓰기 좋은 것들:

| 장면 | EasyMindMap의 배려 |
|---|---|
| 코드 블록 뒤에 이어 쓴 글 | 패널 아래, 원문 순서 그대로 표시 |
| 코드 블록 안에서 Enter | 줄바꿈 (블록 밖 Enter만 편집 완료 — 스마트 Enter) |
| 체크박스 | 맵·아웃라인·칸반 어디서든 클릭 한 번으로 완료/미완료 |
| 웹 기사 붙여넣기 | 글과 사진이 원래 순서 그대로, 사진은 파일에 내장 |
| 다크 모드 형광펜 | 노란 띠 위 글자를 진한 색으로 고정해 항상 읽힘 |
| 검색 결과의 코드·표 | 원문 마커 대신 ⧉코드·⊞표·☑/☐로 깔끔하게 요약 |
| 첫 실행 | 확인 대화상자 없음, 필요할 때만 묻기 |
| 큰 맵(수백 노드) | 2%까지 축소, 접힘 칩에 숨은 노드 수 표시 |
| 문서 속 링크 | 노드에선 라벨만 깔끔하게 + 🔗 아이콘으로 첨부(여러 개면 목록), 노트에선 원문 그대로 클릭 |
| AI 대화 내보내기 불러오기 | 중심 노드는 제목만, 머리말(작성 정보 등)은 노트로 첨부 — 중심이 지저분해지지 않음 |

## 문서 갱신 규칙

- 사용자 체감이 있는 기능/개선이 병합될 때, 이 문서의 해당 절(또는
  "세부 배려 모음" 표)에 **일반인 언어로 한 줄** 추가한다.
- 조작 방법은 `docs/user-guide/`가, 기술 구현은 각 feature 문서가
  담당 — 이 문서는 "왜 좋은가"만 말한다.

관련: `vision.md`(비전), `emm-strategy.md`(EMM 개방 전략),
`../user-guide/README.md`(사용자 설명서 목차).
