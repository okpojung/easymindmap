# 16. Search
## SEARCH

* 문서 버전: v2.0
* 작성일: 2026-04-16
* 최종 업데이트: 2026-08-04 — 실제 구현 기준 현행화: **단일 입력창이 텍스트·태그·노트·링크를 동시 부분일치**(종류 배지 표시), 결과 최대 50, 디바운스 없음, 진입은 Ctrl+F 가 아니라 **좌측 검색 탭**, 강조는 클릭한 1건만(딤 없음), ESC/Enter 순회는 HTML 뷰어 전용.
* 참조: `docs/01-product/functional-spec.md § SEARCH`

---

### 1. 기능 목적

* 맵 내 노드를 **텍스트·태그·노트·링크로 빠르게 탐색**하는 기능
* 검색 결과 노드로 캔버스 즉시 이동 (중앙 + 100% 보기)
* 대형 맵에서 원하는 노드를 신속하게 찾을 수 있는 UX 제공

---

### 2. 기능 범위

* 포함:
  * **단일 입력창** — 노드 텍스트·태그·노트·링크를 **동시에** 부분 일치 검색
  * 결과 목록에 일치 위치 **종류 배지**([노드]/[태그]/[노트]/[링크], e2e59)
  * 결과 클릭 시 해당 노드 강조(노란 채움 + 붉은 테두리) + 접힌 조상 펼침 + 화면 중앙 이동
  * 실시간 검색 (입력 즉시 결과 갱신 — 디바운스 없음)

* 제외:
  * 전체 맵 대상 글로벌 검색 (맵 내 검색만)
  * 정규식 검색
  * 첨부파일 본문 OCR·transcript

### 4. 기능 정의 (What)

#### 4.1 검색 UI 구조

```text
┌──────────────────────────────────────┐
│ 🔍 노드 · 태그 · 노트 검색      [✕]    │
├──────────────────────────────────────┤
│ 결과 3건                              │
│  [노드] Apache 설치                   │
│  [태그] MySQL 설정                    │
│  [노트] 서버 보안 설정                 │
├──────────────────────────────────────┤
│ 태그 필터: [긴급] [완료] [기술]        │  ← 패널 하단 태그 목록 (15-tag.md)
└──────────────────────────────────────┘
```

#### 4.2 검색 동작

* 클라이언트 사이드 필터링 (맵 로딩 후 메모리 내 검색)
* 대소문자 구분 없음, 부분 일치 지원
* 입력 변경 시 **즉시** 결과 갱신 — 디바운스 없음 (원안의 300ms 디바운스는 미채택)
* 하나의 검색어가 텍스트·태그·노트·링크에 동시에 적용된다 (필드 선택 UI 없음)

---

### 5. 동작 방식 (How)

#### 5.1 사용자 동작

* **좌측 레일의 검색 탭** 클릭 → 검색 패널 열기 (`Ctrl+F` 단축키는 미구현 — `17-keyboard-shortcuts.md`)
* 키워드 입력 → 실시간 결과 표시 (결과 최대 50)
* 결과 클릭 → 해당 노드 강조 + 접힌 조상 펼침 + 화면 중앙 + 100% 보기
* 강조 해제: 캔버스에서 다른 노드 클릭/조작
* `↑↓` 방향키·`Enter` 순회, `ESC` 해제는 **HTML 내보내기 뷰어 전용** (에디터 미구현)

---

#### 5.2 시스템 처리

* 검색 입력 → 문서 전체 노드의 텍스트·태그·노트·링크를 클라이언트 필터링
* 결과 클릭 → `interactionStore.searchHitId` 설정 (강조 1건) + `documentStore.expandAncestors` + `viewportStore.requestCenterNode`

---

#### 5.3 표시 방식

* 클릭한 결과 노드: **노란 채움(#FFE066) + 붉은 테두리(#DC2626)** — 어떤 스타일보다 우선 (하단 "MVS 구현" 절 참조)
* 비검색 노드: **변화 없음** (원안의 30% 투명도 딤 처리는 미채택)
* 결과 0건: "검색 결과가 없습니다" 표시

---

### 6. 규칙 (Rule)

* 최소 검색어 1자 이상
* 최대 결과 표시 **50개**
* collapsed 노드의 숨겨진 자식도 검색 대상 (결과 클릭 시 조상 자동 펼침)
* 검색 중 캔버스 편집 가능 (상태 유지)

#### 6.1 검색 범위 (구현됨)

- 대상 (단일 입력창 동시 매칭):
  - 노드 텍스트
  - 태그 이름 (`tags` 문자열)
  - 노트 내용
  - 링크 (라벨·URL)
- 제외:
  - 첨부파일 본문 OCR
  - 오디오/비디오 transcript

**클라이언트 전용** — 서버 LIKE/ILIKE 검색은 없다 (문서가 통째로 메모리에 있으므로 불필요).

#### 6.2 향후 확장 [미구현 — 백로그]

1. PostgreSQL Full Text Search + GIN index (전체 문서함 대상 글로벌 검색이 필요해질 때)
2. AI semantic search

---

### 7. 예외 / 경계 (Edge Case)

* **빈 검색어**: 결과 목록 비움 (강조 해제)
* **결과 0건**: 안내 메시지
* **결과 50건 초과**: 상위 50건만 표시

## MVS 구현 — 검색 결과 강조 + 뷰어 검색 (2026-07)

- **에디터**: 검색 패널에서 결과를 클릭하면 해당 노드를 **노란
  채움(#FFE066) + 붉은 테두리(#DC2626, 2.6px)** 로 어떤 스타일보다
  우선해 또렷하게 표시하고(interactionStore.searchHitId), **접힌
  조상을 펼친 뒤 해당 노드를 화면 중앙 + 100% 보기**로 이동한다
  (2026-07: documentStore.expandAncestors +
  viewportStore.requestCenterNode — 이전에는 강조만 하고 맵이
  움직이지 않았다). 캔버스에서 다른 노드를 클릭/조작하면 해제.
- **강조 노드 글자색 = 진한 고정색(#1F1B16)** (2026-07): 다크
  모드에서 밝은 글자가 노란 배경에 묻혀 내용을 읽을 수 없던 문제 —
  에디터(NodeRenderer)·뷰어(drawNode) 동일.
- **HTML 내보내기 뷰어에도 검색 추가 — 에디터 검색 패널과 동일한
  인터페이스** (2026-07 갱신): 헤더 검색창(placeholder "노드 · 태그 ·
  노트 검색", 🔍 아이콘)에 입력하면 **결과 목록 드롭다운**이 뜬다 —
  "결과 N건" + 항목(제목의 일치 구간 mark 강조 · 상위 경로 › 표기 ·
  일치 위치 노드/태그/노트/링크). 결과 클릭 = 노란+붉은 강조 + 접힌
  조상 펼침 + **화면 중앙 + 100% 보기** 이동(에디터와 동일), 클릭
  후에는 **결과 목록이 닫혀** 맵(강조 노드)을 가리지 않는다 — 검색창을
  다시 클릭하면 목록이 다시 열린다(강조·선택 표시 유지).
  Enter = 다음 결과 순회, Esc/비우면 해제, 바깥 클릭 = 목록 닫기
  (강조 유지). 검색 대상도 에디터와 동일(노드·태그·노트·링크).
  Focus 모드 중 검색하면 전체 맵으로 복귀 후 탐색.
- **뷰어 강조 해제 경로** (2026-07 — 에디터와 동일): ① 맵의 다른
  노드 클릭 ② 빈 캔버스 클릭(선택도 함께 해제, Pan 드래그 직후의
  click은 제외) ③ 결과 목록에서 같은 항목 재클릭(토글) ④ Esc/검색어
  비우기.
