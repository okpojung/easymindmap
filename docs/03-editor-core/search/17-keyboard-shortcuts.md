### 1. 기능 목적

* 에디터 주요 기능을 **키보드 단축키로 빠르게 실행**하는 기능
* 마우스 없이도 노드 생성·편집·탐색이 가능한 생산성 UX 제공
* 단축키 도움말 팝업 [미구현 — 백로그]

### 3. 전체 단축키 목록 (실제 배선)

#### 3.1 노드 편집 (KS-01)

| 단축키                    | 기능                    |
| ---------------------- | --------------------- |
| `Space` / `Tab`        | 자식 노드 추가              |
| `Enter` (비편집 상태)       | 형제 노드 추가           |
| `Ctrl+←`               | **부모 노드 추가** (선택 노드 위에 삽입)           |
| `Ctrl+Space`           | 다중 자식 노드 추가 (여러 줄 입력 팝업)    |
| `Delete`               | 선택 노드(서브트리) 삭제 — **`Backspace` 는 배선 없음**              |
| `Ctrl+C`               | 선택 노드 **서브트리 복사** (내부 클립보드 `nodeClipboard` — 시스템 클립보드에는 토큰만, e2e94)   |
| `Ctrl+V`               | 복사한 서브트리를 **선택 노드의 하위로** 붙여넣기                  |
| 더블클릭                   | 텍스트 편집 모드 진입 (**`F2` 는 아웃라인 모드 전용**)          |
| `Ctrl+D` (노드 복제)       | [미구현 — 백로그]                 |

**편집 중 (텍스트 입력 모드):**

| 단축키              | 기능              |
| ---------------- | --------------- |
| `Enter`          | 편집 커밋 (스마트 Enter — 열린 코드 펜스 안에서는 줄바꿈, e2e57) |
| `Shift+Enter`    | 줄바꿈             |
| `Esc`            | 편집 취소           |

#### 3.2 선택 (KS-02)

| --------------- | ------------- |
| 클릭              | 단일 선택         |

#### 3.3 캔버스 조작 (KS-03)

| 단축키              | 기능              |
| ---------------- | --------------- |
| `+` (수정자 없음)         | Zoom In         |
| `-` (수정자 없음)         | Zoom Out        |
| `0` (수정자 없음)         | **보기 초기화** (100% + 위치 리셋)       |
| `Alt+F`          | 선택 노드 화면 중앙 |
| `H` (한글 자판 `ㅗ` 동일)              | Pan 모드 토글       |
| 휠클릭 드래그 / 우클릭 드래그      | 임시 Pan (원안의 `Space+드래그` Pan 은 미채택 — Space 는 자식 추가)      |
| 전체 맞춤 (Fit)   | 툴바 버튼 (단축키 없음 — 원안 `Ctrl+Shift+F` 미채택)      |
| 선택 노드 중앙   | 버튼/검색 결과 클릭 (원안 `Ctrl+Enter` 미채택)     |
| 전체화면            | 툴바 버튼 (원안 `F11` 미채택 — 브라우저 기본 동작만)      |

### 4. Kanban 레이아웃 단축키 (KS-06)

칸반 모드에서 동작하는 키보드는 **`Delete`(선택 카드/컬럼 서브트리 삭제) ·
`Ctrl+C`/`Ctrl+V`(카드 서브트리 복사 → 선택 대상 하위로 붙여넣기, e2e94) ·
`Esc`(선택 해제)** 뿐이다. 컬럼/카드 추가는 보드 UI 버튼으로 한다.

> 원안의 "depth 별 `Space`/`Shift+Space` 동작 차이" 규칙은 미채택 —
> 칸반에서는 노드 추가 단축키가 배선되지 않았다.

---

### 5. 단축키 도움말 팝업 (KS-07) [미구현 — 백로그]

원안의 `?` / `Ctrl+/` 도움말 팝업은 구현하지 않았다. 구현 시 §3 의 실제
배선 표를 기준으로 한다.

---

### 6. 규칙

* 텍스트 편집 모드에서는 캔버스 단축키 비활성 (입력 충돌 방지)
* 편집 중 `Esc` = 편집 취소, 비편집 상태 `Esc` = 선택 해제 — 원안의 4단계 ESC 우선순위 체인(편집 종료 > 검색 닫기 > 선택 해제 > Fullscreen 종료)은 미구현
* 칸반 모드에서는 §4 의 키만 동작
