# 30. 주소록 — 협업맵 참여자를 고르는 내 연락처

> **2026-10-14 사용자 요청**: "협업맵에 참여자를 추가·선택하기 위해 먼저 주소록 기능을
> 개발해줘. 주소록은 그룹관리가 되어야 하며 주소록은 이메일과 (이름)…"
> 참고 화면은 소속(그룹) 트리 + 이름·이메일 목록 + **[참여자로 추가]** 가 있는 창이었다.
>
> **유료 기능**이다(협업의 일부 — `open-core-boundary.md` §3). 구현은 비공개 저장소,
> 이 문서는 설계만 적는다.

## 1. 무엇을 하나

| | |
|---|---|
| 소속(그룹) | 만들기 · 이름 바꾸기 · 지우기. **조직 구조대로 여러 단계**(6단계까지) · 처음부터 있는 **'기본'** 그룹 |
| 연락처 | **이름 + 이메일**. 추가 · 고치기 · 지우기 · 다른 그룹으로 옮기기 · **회원/미가입 표시** |
| 찾기 | 이름·이메일·그룹 이름의 **일부**로, 주소록 전체에서 |
| 고르기 | 체크는 그룹을 옮겨 다녀도 남는다 — 여러 그룹에서 골라 한 번에 |
| 초대 | 공유 창 ▸ **[주소록]** ▸ 고르고 **[참여자로 추가 (역할)]** · 공유 창 이메일 칸 **자동완성** |

## 2. 결정

1. **사람마다 따로다.** 주소록은 계정에 붙는다(`owner_id`). 남의 그룹·연락처 id 를
   들고 와도 "없다"(404) — 있는지조차 알려 주지 않는다.
2. **주소록은 초대가 아니다.** 주소록에 넣는다고 누가 맵에 들어오지 않는다.
   [참여자로 추가] 는 고른 이메일로 **기존 초대 경로**를 차례로 부른다
   (`29-invite-and-ownership-transfer.md` §2). 가입자는 곧바로 참가자, 미가입자는
   초대장 — 갈래와 "퍼블리싱 맵에는 초대 불가" 규칙이 한 곳에 남는다.
3. **연락처는 그룹 하나에만 든다.** 한 주소록에 같은 이메일은 한 번(대소문자 무시) —
   두 벌을 두지 않고 옮긴다. 중복으로 거절할 때는 **누구이고 어느 그룹에 있는지**를
   말한다("중복입니다" 만으로는 찾을 수 없다).
4. **그룹을 지워도 사람은 지우지 않는다.** 든 연락처는 '그룹 없음'으로 옮겨 간다 —
   사람을 잃는 것이 그룹을 잃는 것보다 비싸다.
5. **지우기는 그 자리에서 한 번 더 묻는다**(브라우저 확인창을 쓰지 않는다 — 모바일·
   자동화에서 막힌다).
6. **가입 여부는 저장하지 않고 열 때마다 계산한다** (2026-10-14 사용자 요청 — 처음 결정
   "적지 않는다" 를 바꿨다). 넣을 때 미가입이던 사람이 그 뒤 가입하면 다음에 열 때 '회원' 이다.
7. **'기본' 그룹은 처음부터 있다** (2026-10-14 사용자 요청). 그룹을 고르지 않고 넣은 사람,
   지운 그룹에 들어 있던 사람이 여기 든다. 지우거나 이름을 바꿀 수 없고, 맨 위에 같은
   이름의 그룹을 따로 만들 수 없다.

## 3. 저장

유료 표 둘(`collab_` 접두사 — 코어 헬스체크 `REQUIRED_TABLES` 에 넣지 않는다):
`collab_contact_groups`(소유자 · 이름 — 소유자 안에서 이름 유일) ·
`collab_contacts`(소유자 · 그룹(없으면 NULL) · 이름 · 이메일 — 소유자 안에서 이메일 유일).
그룹을 지우면 `ON DELETE SET NULL`. 표가 없는 서버에서는 주소록만 "스키마가 아직
적용되지 않았다" 로 답하고, 초대·협업은 그대로 돈다.

## 5. 관리자 ▸ 주소록관리 (2026-10-14 사용자 요청)

"관리자 메뉴에서 팀구독자 대상으로 주소록 관리화면 — 조직 구조에 맞게 등록, 엑셀 대량 등록."

- 관리자 콘솔(`/admin`)의 **주소록관리** 탭. `collab` 이 켜진 서버에서만 나온다
  (탭 자리는 코어, 알맹이는 유료 — `ProContactsAdminPanel`).
- 왼쪽에서 **요금제가 `team` 인 회원**을 찾아 고르면, 오른쪽에 그 회원의 주소록이
  사용자 화면과 같은 모양으로 열린다. 관리자가 고친 것은 그 회원의 주소록 그대로다.
  팀 요금제가 아닌 회원의 주소록은 열지 않는다.
- **엑셀(.xlsx)·CSV 올리기** — 열은 `소속 · 이름 · 이메일`. 소속은 `본부/팀` 처럼 경로로
  쓰고, 없는 그룹은 단계마다 만든다. 비우면 '기본'. 올리기 전에 줄마다 확인해 보여 주고,
  틀린 줄은 번호와 까닭을 돌려준다(나머지는 들어간다). 이미 있는 이메일은 "덮어쓰기" 를
  켰을 때만 이름·소속을 바꾼다. [양식 받기]로 빈 양식(CSV)을 내려받는다.

## 4. 다음 단계 (같은 요청의 나머지)

참고 화면에는 주소록 말고도 협업 패널과 메뉴가 있었다. 순서대로 잇는다.

1. ~~**협업초대 창 개편**~~ — **완료 (2026-10-14)**: 이름·그룹·이메일 일부로 자동완성(그룹을 고르면 그
   그룹·하위 사람 모두), 이메일은 쉼표·붙여넣기로 여러 개, [주소록]에서 고른 사람도 **칩으로만** 담기고
   [확인] 한 번에 초대. 실패한 사람은 칩에 서버 까닭을 달고 남는다. [협업 링크 복사] 는 맵 주소(참여자만 열린다)
2. **협업 패널** — 참여자를 주소록 소속별로 묶어 접속 상태와 함께 보여 준다.
   ⋯ 메뉴: 간략하게 보기 · 편집권한 설정 · 마우스포인터 공유 · 개설자 변경
   (개설자 변경 = 기존 소유권 이전, §29 §3)
3. **일시정지 · 비밀번호 설정** — 서버 동작이 새로 필요하다(협업 방을 멈추기, 맵 열기 전 비밀번호)

주소록을 계정 메뉴에서 바로 여는 자리는 코어에 자리(`@pro` 확장점)를 하나 내야 해서
2번과 함께 한다.
