# 테스트 카탈로그 (MVS E2E)

> **이 문서의 역할**: MVS(에디터 프런트엔드) 개발 과정에서 각 PR마다
> 작성·실행한 Playwright E2E 테스트를 **기능 영역별로** 정리한 회귀
> 검증 목록이다. "무엇이 이미 검증되어 있는가"를 한눈에 보고, 회귀
> 실행 시 어떤 테스트를 돌려야 하는지 고르는 기준표다.
>
> **갱신 규칙 (중요)**: 코드가 업데이트되어 **새 E2E를 추가하거나 기존
> 테스트를 바꿀 때마다 이 문서도 함께 갱신**한다. 각 배치 작업의
> 커밋에 테스트 파일과 이 표의 변경을 같이 담는다. (feature 문서의
> "검증: E2E eNN" 문구와 짝을 이룬다.)

---

## 1. 개요

- **도구**: Playwright(Chromium) — 실제 브라우저에서 앱을 구동하고
  DOM·SVG 좌표를 실측하는 통합 테스트. 단위 테스트가 아니라 **사용자
  시나리오 재현** 방식이다.
- **실행 환경**: 개발 서버(`apps/frontend`, Vite) + 헤드리스 Chromium.
  테스트 스크립트는 세션 스크래치패드에 `eNN.cjs`로 보관한다(저장소에
  커밋하지 않는 개발 자산 — 산출물은 이 카탈로그와 feature 문서의 검증
  문구).
- **검증 데이터**: 합성 입력 + **실제 파일**(was.md 전자영수증,
  ubuntu-wp.html 352노드 WordPress 가이드, ChatGPT 대화 내보내기 등)로
  실사용 시나리오를 재현한다.
- **판정 방식**: 각 테스트는 `PASS/FAIL` 체크를 출력하고 하나라도
  실패하면 비정상 종료한다. 좌표·색상·개수를 **실측**해 비교한다
  (스냅샷 이미지가 아니라 계산값 단언).
