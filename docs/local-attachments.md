# 이 PC 첨부

프로필의 **이 PC 첨부 폴더**에서 폴더를 선택한다. 지원하는 데스크톱 브라우저의 File System Access API를 사용하며 절대경로를 직접 입력하지 않는다. 폴더 접근은 읽기 전용이다. 처음 첨부 메뉴에서 시작하면 첫 클릭은 폴더 연결, 다음 클릭은 파일 선택이다.

맵에는 `emm-local://폴더UUID/인코딩된/상대경로`와 파일 이름·크기·종류만 저장한다. 실제 폴더 핸들 및 승인한 파일 경로는 해당 PC·브라우저·계정의 IndexedDB에 둔다. 핸들을 서버나 맵 파일로 보내지 않으며 파일 내용은 업로드하지 않는다. 서버 첨부 용량을 소비하지 않는다. 다른 PC나 공동 작업자에게 파일이 자동 전달되지 않으므로 필요하면 별도로 전달하거나 기존 서버 첨부로 다시 추가한다.

## 표시와 복구

- **서버**: 서버 첨부 저장소의 파일.
- **이 PC**: 연결 폴더의 상대경로 참조.
- **이 PC · 연결 끊김**: 폴더 연결 또는 읽기 권한 확인 실패. 열기를 누르면 안내와 **폴더 다시 연결**을 제공한다.
- **맵 내장**: 맵 데이터 안에 포함된 파일. 서버 첨부로 잘못 분류하지 않는다.
- **링크**: 그 외 외부 참조.

폴더는 연결됐지만 파일이 없으면 **폴더 안에서 첨부파일을 찾을 수 없습니다**로 구분한다. 참조를 자동 삭제하거나 다른 파일로 바꾸지 않는다. 연결 해제는 브라우저의 연결 정보만 지우며 실제 파일은 삭제하지 않는다.

## 권한과 안전

폴더 전체를 선택한 것과 개별 파일을 맵에 연결한 것을 구분한다. 맵 메타데이터를 바꿔 임의의 다른 파일을 읽을 수 없다. 처음 선택하지 않은 상대경로는 **파일 확인·연결**에서 정확한 파일을 다시 선택해야 한다. 같은 실제 폴더임을 확인할 수 없거나 다른 PC에서 연결하면 파일을 다시 확인해야 한다. 로그아웃·계정 전환 시 이전 계정의 핸들과 승인을 폐기하므로 재로그인 후 재연결이 필요할 수 있다. 보안을 위해 전용 첨부 폴더를 권장한다.

로컬 MD는 읽기 전용으로 열며 로컬 파일을 수정하지 않는다. HTML·SVG·XHTML 및 알 수 없는 실행 가능 형식은 앱 출처의 문서로 열지 않고 다운로드한다. 열린 로컬 미리보기는 계정 전환 시 닫는다.

## 저장·내보내기

일반 맵 저장과 Markdown/MMD 참조 내보내기는 파일 바이트를 읽지 않는다. HTML/JSON 및 선언형 Markdown에 상대 참조가 보존된다. 파일 바이트를 포함하는 내보내기는 명시적으로 수행하며 기존 20 MiB 패키지 제한을 완화하지 않는다. 연결/권한/승인 실패나 크기 초과 시 부분 패키지를 성공으로 내보내지 않는다. 참조만 남은 독립 HTML은 연결 안내를 보여 주며, 로컬 프로토콜을 외부 프로그램으로 실행하지 않는다. 암호화 포장 규칙은 기존 정책을 따른다.

모의 폴더·IndexedDB·권한 전환으로 회귀 검증한다. 실제 OS 폴더 선택창, 이동식 드라이브 및 OS 심볼릭 링크 동작은 모의 검증이 증명하지 않는다. 브라우저가 권한을 회수하거나 사이트 데이터를 지우면 연결을 다시 허용해야 한다. 로컬 원본은 서버 백업에 포함되지 않는다.
