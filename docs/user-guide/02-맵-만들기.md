# 02. 맵 만들기

## 새 맵 만들기

1. 왼쪽 레일에서 **`+ 새 맵`** 아이콘을 누릅니다.
2. **`+ 새 맵 만들기`** 버튼을 누릅니다. **제목은 묻지 않습니다** —
   맵 이름은 나중에 **☁ 저장**할 때 폴더와 함께 정합니다. 그전까지
   제목은 "새 맵"입니다.
3. **편집한 내용이 있을 때만** "현재 맵을 닫고 진행할까요?" 확인이
   나옵니다 — `현재 맵 닫고 계속`을 누르면 교체됩니다 (`Ctrl+Z`로 복구
   가능). 앱을 막 켜서 아무것도 고치지 않은 상태(파일 불러오기도
   마찬가지)에서는 잃을 것이 없으므로 묻지 않고 바로 진행합니다.

### 기본 템플릿 — 트리-진행트리맵

새 맵은 **'트리-진행트리맵'** 골격으로 시작합니다:
중심 주제 + 주제 1~3 (주제 1·2 = 하위 주제 + 내용 2개, 주제 3 =
하위 주제만) — 모두 11개 노드로 시작합니다. 레벨별 레이아웃은
1레벨 트리·오른쪽 → 2레벨 진행트리 → 3레벨 트리 → 4레벨 진행트리입니다.

## 템플릿에서 시작

새 맵을 만들거나 파일을 불러온 **직후**, "적용할 템플릿 선택" 단계가
나옵니다 (내 템플릿 + 라이브러리 목록):

- **새 맵을 만든 직후**에 고르면 → 그 템플릿의 **골격(4레벨 자리 표시
  텍스트: 중심 주제·주제 1~n·하위 주제·내용)과 레이아웃·스타일**로
  시작합니다.
- **파일을 불러온 직후**에 고르면 → 불러온 내용은 그대로 두고
  **레이아웃·스타일만** 입혀집니다.
- 그냥 쓰려면 `건너뛰기(기본 그대로)`.
- AI로 초안부터 만들려면 `🌐 AI로 초안 만들기 (웹 AI · 키 불필요)` 를
  누르세요 — AI 탭이 웹 AI 모드로 열립니다.
- **마음이 바뀌었으면 오른쪽 위 `✕`** — 새 맵 만들기가 취소되고, 보고
  있던 맵이 그대로 남습니다. 새 맵은 이 단계에서 무엇이든 고른 **뒤에**
  만들어지므로, 취소해도 잃는 것이 없습니다.

> **직접 칠한 노드 색은 지워지지 않습니다** — 강조하려고 채움·테두리·
> 글자색을 바꿔 둔 노드(같은 레벨의 다른 노드들과 다른 색)는 템플릿을
> 적용해도 그 색을 유지합니다. 레벨 전체가 같은 색(이전 템플릿의
> 스타일)인 부분만 새 템플릿 색으로 갈아입혀집니다.

기본 제공 라이브러리 템플릿(7종):
- **트리-진행트리맵** (기본)
- 진행트리-트리맵
- 브레인스토밍 (방사형·양쪽)
- 제품 로드맵
- WBS 프로젝트
- Kanban 보드 (주제 1~4 컬럼 기본 보드)
- 회의록

## 내 템플릿 등록

지금 만든 맵을 나중에 재사용하려면, 템플릿 패널에서 이름을 입력하고
**`등록`** 을 누르면 됩니다(이름을 비우면 맵 제목이 쓰입니다). 등록한
템플릿은 새 맵/불러오기 직후의 템플릿 선택 단계에 나타납니다.
