# 02. 맵 만들기

## 새 맵 만들기

1. 왼쪽 레일에서 **`+ 새 맵`** 아이콘을 누릅니다.
2. (선택) 맵 제목을 입력합니다. 비우면 자동으로 정해집니다.
3. **`+ 새 맵 만들기`** 버튼을 누릅니다.
4. 편집 중이던 맵이 있으면 **"현재 맵을 닫고 진행할까요?"** 확인이
   나옵니다 — `현재 맵 닫고 계속`을 누르면 교체됩니다 (`Ctrl+Z`로 복구
   가능).

### 기본 템플릿 — 트리-진행트리맵

새 맵은 **'트리-진행트리맵'** 골격으로 시작합니다:
중심 주제 + 주제 1~3 + 각 하위 주제 + 내용(4레벨). 레벨별 레이아웃은
1레벨 트리·오른쪽 → 2레벨 진행트리 → 3레벨 트리 → 4레벨 진행트리입니다.

## 템플릿에서 시작

새 맵을 만들거나 파일을 불러온 **직후**, "적용할 템플릿 선택" 단계가
나옵니다. 원하는 템플릿을 고르면 내용은 그대로 두고 **레이아웃·스타일**만
입혀집니다. 그냥 쓰려면 `건너뛰기(기본 그대로)`.

기본 제공 라이브러리 템플릿(7종):
- **트리-진행트리맵** (기본)
- 진행트리-트리맵
- 브레인스토밍 (방사형·양쪽)
- 제품 로드맵
- WBS 프로젝트
- Kanban 보드
- 회의록

### 이 템플릿으로 시작 (골격째 새로)

레일 아래쪽 **"등록된 템플릿에서 시작"** 에서 `이 템플릿으로 시작`을
누르면, 그 템플릿의 구조(4레벨까지)를 자리표시 텍스트(중심 주제·주제
1~n·하위 주제·내용)로 채운 새 맵이 만들어집니다.

## 내 템플릿 등록

지금 만든 맵을 나중에 재사용하려면, 템플릿 패널에서 **템플릿으로 등록**할
수 있습니다. 등록한 템플릿은 "새 맵" 화면에 나타납니다.
