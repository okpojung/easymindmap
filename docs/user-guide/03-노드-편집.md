# 03. 노드 편집

## 노드 추가

노드를 하나 선택한 뒤:

| 방법 | 결과 |
|---|---|
| 노드에 마우스를 올리면 나오는 **`+` 버튼** | 그 방향으로 노드 추가 |
| `Space` | 자식 노드 추가 |
| `Shift+Space` | 아래 형제 노드 추가 |
| `Tab` (편집 끝낸 뒤) | 자식 노드 추가 |
| 오른쪽 위 도구의 **노드 `+`** | 선택 노드에 자식 추가 |

## 글자 편집

- 노드를 **더블클릭**(또는 `F2`)하면 글자를 고칠 수 있습니다.
- 편집 중 `Enter` = 줄바꿈, `Esc` = 편집 끝내기.
- 여러 줄로 길게 써도 됩니다.

## 노드 삭제

노드를 선택하고 `Delete`(또는 `Backspace`), 또는 오른쪽 위 도구의
**휴지통** 아이콘. 하위 노드까지 함께 지워집니다.

## 노드 이동 (드래그)

노드를 끌어서 다른 노드의 위/아래/자식 위치로 옮길 수 있습니다.
방사형·양쪽 레이아웃에서는 반대쪽 빈 공간으로 끌면 그쪽 가지로
바뀝니다 (끌 때 "왼쪽으로 이동" 같은 안내 배지가 나옵니다).

## 부분 강조 (굵게·형광펜·코드 등)

글자 편집 중 일부를 선택하면 위에 작은 툴바(**B** 굵게 / *I* 기울임 /
~~S~~ 취소선 / U 밑줄 / H 형광펜 / `<>` 코드)가 뜹니다. 버튼을 누르면
그 구간만 강조됩니다. 단축키 `Ctrl+B` / `Ctrl+I` / `Ctrl+U`도 됩니다.

- **`<>` 코드**: 선택한 글자가 고정폭 글꼴 + 회색 배경으로 표시됩니다
  (명령어·파일명·함수 이름에 적합). 백틱(`` ` ``)으로 직접 감싸도 됩니다.
- **`{ }` 코드 블록**: 여러 줄 코드를 노드 안에 **패널**(언어 라벨 +
  ⧉ 복사 버튼 포함)로 넣습니다. 버튼을 누르면 ``` 블록이 삽입되고,
  **블록 안에서는 Enter가 줄바꿈**으로 동작합니다(블록 밖에서는 Enter=
  편집 완료). 손으로 ```` ```bash ````처럼 입력해도 같습니다 — 여는
  펜스를 친 뒤부터는 Enter로 줄을 이어가고, 닫는 ``` 뒤 Enter로
  편집이 끝납니다.
- **코드 블록 언어 설정** (두 가지 방법):
  1. 편집 중 여는 펜스에 직접 씁니다 — ```` ```bash ````, ```` ```python ````
     처럼. 비워 두면 라벨이 `code`로 표시됩니다.
  2. 편집을 마친 뒤 **패널 왼쪽 위 언어 라벨을 클릭**하면 입력창이 떠서
     언어를 바꿀 수 있습니다 (비우면 `code`).
- `<>`(인라인 코드)와 `{ }`(코드 블록)는 **서로 다른 기능**입니다 —
  인라인 코드는 문장 속 한 구간(헤더 없음), 코드 블록은 여러 줄 패널
  (언어 라벨·복사 버튼 포함)입니다.

## 사진·기사 붙여넣기

- **그림 복사 후 붙여넣기**(`Ctrl+V`): 노드에 사진이 들어갑니다.
- **웹 기사 복사 후 붙여넣기**: 글과 사진이 **원래 순서 그대로** 노드에
  들어갑니다 (사진은 텍스트 중간 제자리에). 사진은 맵 파일에 **내장**되어
  기사가 사라져도 보존됩니다.
- 노드를 **선택만** 한 상태에서 붙여넣으면 → 그 아래 새 하위 노드가
  생기고 내용이 통째로 들어갑니다.
- 노드를 **편집 중**에 붙여넣으면 → 글자는 커서 위치에, 사진은 노드에
  함께 (저장 시 반영).
