# 03. 노드 편집

## 노드 추가

노드를 하나 선택한 뒤:

| 방법 | 결과 |
|---|---|
| 노드에 마우스를 올리면 나오는 **`+` 버튼** | 그 방향으로 노드 추가 |
| `Space` | 자식 노드 추가 |
| `Shift+Space` | 아래 형제 노드 추가 |
| `Tab` (편집 끝낸 뒤) | 자식 노드 추가 |
| 오른쪽 위 도구의 **노드 `+`** | 선택 노드에 자식 추가 |

## 글자 편집

- 노드를 **더블클릭**(또는 `F2`)하면 글자를 고칠 수 있습니다.
- 편집 중 `Enter` = 줄바꿈, `Esc` = 편집 끝내기.
- 여러 줄로 길게 써도 됩니다.

## 노드 삭제

노드를 선택하고 `Delete`(또는 `Backspace`), 또는 오른쪽 위 도구의
**휴지통** 아이콘. 하위 노드까지 함께 지워집니다.

## 노드 이동 (드래그)

노드를 끌어서 다른 노드의 위/아래/자식 위치로 옮길 수 있습니다.
방사형·양쪽 레이아웃에서는 반대쪽 빈 공간으로 끌면 그쪽 가지로
바뀝니다 (끌 때 "왼쪽으로 이동" 같은 안내 배지가 나옵니다).

## 부분 강조 (굵게·형광펜·코드)

글자 편집 중 일부를 선택하면 위에 작은 툴바(**B** 굵게 / *I* 기울임 /
~~S~~ 취소선 / U 밑줄 / H 형광펜 / `{ }` 코드 블록)가 뜹니다. 버튼을
누르면 그 구간만 강조됩니다. 단축키 `Ctrl+B` / `Ctrl+I` / `Ctrl+U`도 됩니다.

## 코드 블록 (`{ }`)

- 툴바의 **`{ }` 버튼을 누르면 팝업 창**이 뜹니다 — **언어와 코드를
  팝업에서 입력**하고 확인을 누르면 노드에 코드 **패널**(언어 라벨 +
  ⧉ 복사 버튼)로 들어갑니다. 작은 노드 안에서 여러 줄 코드를 직접
  칠 필요가 없습니다.
- **수정**: 이미 만든 코드 패널을 **더블클릭**하거나 **언어 라벨(✎)을
  클릭**하면 같은 팝업이 언어·코드가 채워진 채 열립니다. 언어만 바꿔도
  되고 코드를 고쳐도 됩니다 (언어를 비우면 `code`로 표시).
  **아웃라인·칸반의 코드 패널에서도 언어 라벨(✎)을 클릭**하면 같은
  팝업이 열립니다 — 맵으로 돌아갈 필요가 없습니다.
- **직접 타이핑도 가능**: 편집 중 ```` ```bash ````처럼 여는 펜스를 치면
  그때부터 **Enter가 줄바꿈**으로 동작하고, 닫는 ``` 뒤 Enter로 편집이
  끝납니다.
- **글 순서는 그대로**: 코드 블록 위에 쓴 글은 패널 위에, 아래에 쓴 글은
  패널 아래에 표시됩니다 (`Shift+Enter`로 블록 뒤에 이어 쓸 수 있습니다).
- 문장 속 **한 구간만 코드**로 표시하려면 백틱(`` ` ``)으로 감싸면
  됩니다 — `` `npm install` `` 처럼 (고정폭 + 회색 배경).

## 체크박스 (☑)

- 편집 중 툴바의 **☑ 버튼**을 누르면 커서가 있는 줄이 체크 항목
  (`- [ ] `)이 됩니다 (다시 누르면 해제). 직접 `- [ ] 할 일`처럼
  타이핑해도 같습니다 (`- [x]` = 완료).
- 편집을 마치면 마커 대신 **체크박스**가 그려집니다 — **클릭하면
  완료↔미완료가 토글**됩니다 (편집에 들어갈 필요 없음).
- 한 노드에 여러 항목을 넣으려면 `Shift+Enter`로 줄을 나눠 항목을
  이어 쓰면 됩니다. 내보낸 HTML 뷰어에서도 같은 모양으로 보입니다
  (뷰어는 읽기 전용).
- **아웃라인·칸반에서도 똑같이** 체크박스·코드 패널·표가 보이고,
  체크박스는 그 화면에서 바로 클릭해 토글할 수 있습니다. 검색 결과나
  선택 노드 요약처럼 한 줄로 보여주는 곳에서는 마커 원문 대신
  **☑/☐ · ⧉코드 · ⊞표**로 접어 표시됩니다.

## 사진·기사 붙여넣기

- **그림 복사 후 붙여넣기**(`Ctrl+V`): 노드에 사진이 들어갑니다.
- **웹 기사 복사 후 붙여넣기**: 글과 사진이 **원래 순서 그대로** 노드에
  들어갑니다 (사진은 텍스트 중간 제자리에). 사진은 맵 파일에 **내장**되어
  기사가 사라져도 보존됩니다.
- 노드를 **선택만** 한 상태에서 붙여넣으면 → 그 아래 새 하위 노드가
  생기고 내용이 통째로 들어갑니다.
- 노드를 **편집 중**에 붙여넣으면 → 글자는 커서 위치에, 사진은 노드에
  함께 (저장 시 반영).
