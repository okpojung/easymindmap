# 04. 레이아웃과 보기

## 레이아웃 바꾸기

**중심 주제(또는 원하는 노드)를 선택**한 뒤, 왼쪽 속성의 **`레이아웃`
탭**에서 종류를 고릅니다.

| 레이아웃 | 모양 |
|---|---|
| 방사형 · 양쪽 | 중심에서 좌우로 뻗음 |
| 방사형 · 오른쪽 | 오른쪽으로만 |
| 트리 · 오른쪽 | 아래로 들여쓴 목록 |
| 트리 · 아래 | 가로로 펼침 |
| 계층형 · 오른쪽 | 조직도 형태 |
| 진행트리 · 오른쪽 | 왼쪽 정렬 가로 전개 |
| 시간배치 | 가로 시간축 |
| 자유 배치 / Kanban | 자유 위치 / 보드 |

> 레벨마다 다른 레이아웃을 줄 수도 있습니다(맵 설정 또는 노드별 지정).

## 접기 / 펼치기

- 노드에 자식이 있으면 **접기 토글**이 보입니다. 접으면 하위가 숨고,
  숨은 노드 수가 **숫자 배지(+N)** 로 표시됩니다.
- 오른쪽 위 도구의 **`+`(모두 펼치기) / `−`(모두 접기)** — 모두 접기는
  2레벨만 남기고 전부 접습니다.

## 줌 (확대/축소)

- 하단 상태바의 **`−` / `+`** 버튼: 5%씩 확대/축소.
- 가운데 **`NN%` 숫자를 클릭**하면 원하는 배율을 직접 입력할 수 있습니다
  (2~400).
- **100% 보기** 아이콘: 실제 크기로.
- `Ctrl + 마우스 휠`로도 확대/축소.

## 화면 맞추기 · 중앙 보기

- 오른쪽 위 **화면 맞추기**(⛶): 맵 전체가 화면에 들어오게.
- **중앙 보기**(⌖): 선택한 노드를 화면 가운데로.

## 아웃라인 분할 보기

왼쪽 레일의 **아웃라인 아이콘**을 켜면 화면이 좌(글 목록)/우(맵)로
나뉩니다. 글 목록에서 바로 편집할 수 있고, 맵과 실시간으로 연동됩니다:

- **아웃라인에서 노드 클릭** → 맵에서 그 노드가 가운데로 오고 **노란색
  강조**로 표시됩니다.
- **맵에서 노드 클릭** → 아웃라인이 그 줄로 자동으로 스크롤됩니다.
