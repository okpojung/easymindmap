# 04. 레이아웃과 보기

## 레이아웃 바꾸기

왼쪽 속성의 **`레이아웃` 탭**에서 종류를 고릅니다. 적용 범위는 선택
상태에 따라 정해집니다:

- **아무 노드도 선택하지 않음** 또는 **중심 주제 선택** → **맵 전체**에
  적용됩니다. 큰 맵에서 중심 주제를 찾아갈 필요 없이, 빈 캔버스를 한 번
  클릭(선택 해제)하고 바로 레이아웃을 고르면 됩니다.
- **하위 노드 선택** → 그 노드의 **하위 가지(서브트리)에만** 적용됩니다
  (맵 전체 전용 레이아웃은 흐리게 표시).

| 레이아웃 | 모양 |
|---|---|
| 방사형 · 양쪽 | 중심에서 좌우로 뻗음 |
| 방사형 · 오른쪽 | 오른쪽으로만 |
| 트리 · 오른쪽 | 아래로 들여쓴 목록 |
| 트리 · 아래 | 가로로 펼침 |
| 계층형 · 오른쪽 | 조직도 형태 |
| 진행트리 · 오른쪽 | 왼쪽 정렬 가로 전개 |
| 시간배치 (타임라인) | 가로 시간축 (중심 주제가 축의 왼쪽 끝) |
| 시간배치 (중앙노드) | 가로 시간축이 **중심 주제를 관통** — 주제가 좌·우로 나뉘어 맵이 한쪽으로만 길어지지 않습니다 |
| Kanban 보드 | 컬럼형 보드 |
| 자유 배치 | 노드를 자유 위치에 |

> 레벨마다 다른 레이아웃을 줄 수도 있습니다(맵 설정 또는 노드별 지정).

- **되돌리기(Ctrl+Z)는 레이아웃 전환도 함께 되돌립니다** — 예를 들어
  진행트리에서 Kanban으로 바꾼 뒤 되돌리면 맵 내용과 함께 진행트리
  화면으로 돌아옵니다.
- **Kanban 카드 속 넓은 표·코드**는 카드(컬럼 폭 300px) 안에서 **가로
  스크롤**로 담깁니다 — 옆 컬럼을 침범하지 않습니다. 긴 URL·경로는
  자동으로 줄바꿈됩니다. **스크롤 영역에서는 카드 드래그가 시작되지
  않아** 스크롤바를 안심하고 조작할 수 있습니다 (카드 이동은 제목 등
  다른 부분을 잡고 끌기).
- **Kanban에서도 맵과 똑같이**: 카드를 선택해 `Del` 키로 삭제(하위
  포함), **빈 곳을 드래그해 여러 카드를 한 번에 선택**(러버밴드) —
  선택된 카드들에 스타일 일괄 적용·`Del` 일괄 삭제(되돌리기 1단계)가
  됩니다. 노드에 지정한 **채움·테두리·글자색도 카드/컬럼에 그대로**
  보입니다 (어두운 채움이면 읽기 좋은 밝은 글자 자동).
- **컬럼(주제)을 지우려면** 컬럼 헤더를 클릭해 선택한 뒤 `Del` —
  헤더 더블클릭은 이름 편집입니다.
- Kanban에도 **우상단 도구**가 있습니다 — 노드 `+`/휴지통, **선택
  카드가 보이게 스크롤**, **보드 처음으로**, **전체화면**.
  (Pan·모두 접기/펼치기는 보드에 없어 숨겨집니다.)
- Kanban에서도 `Ctrl+C` 복사 / `Ctrl+V`(선택 카드·컬럼의 하위로
  삽입) / `Esc` 선택 해제가 됩니다.

## 접기 / 펼치기

- 노드에 자식이 있으면 **접기 토글**이 보입니다. 접으면 하위가 숨고,
  숨은 노드 수가 **숫자 배지(+N)** 로 표시됩니다.
- 오른쪽 위 도구의 **`+`(모두 펼치기) / `−`(모두 접기)** — 모두 접기는
  2레벨만 남기고 전부 접습니다.

## 줌 (확대/축소)

왼쪽 아래에는 **이 맵의 무게**가 나옵니다 — `문서 46.1KB · 첨부 3개 ·
26.7MB`. 요금제 한도가 문서+첨부 합산이라(계정 메뉴 > 저장 용량), 어느
맵이 용량을 먹는지 여기서 바로 보입니다. 편집하면 문서 크기가 곧바로
따라 움직입니다.

- 하단 상태바의 **`−` / `+`** 버튼: 5%씩 확대/축소.
- 가운데 **`NN%` 숫자를 클릭**하면 원하는 배율을 직접 입력할 수 있습니다
  (2~400).
- **100% 보기** 아이콘: 실제 크기로.
- `Ctrl + 마우스 휠`로도 확대/축소.

- 오른쪽 위 **화면 맞추기**(⛶): 맵 전체가 화면에 들어오게.
- **중앙 보기**(⌖): 선택한 노드를 화면 가운데로.

## 아웃라인 분할 보기

왼쪽 레일의 **아웃라인 아이콘**을 켜면 화면이 좌(글 목록)/우(맵)로
나뉩니다. 글 목록에서 바로 편집할 수 있고, 맵과 실시간으로 연동됩니다:

- **아웃라인에서 노드 클릭** → 맵에서 그 노드가 가운데로 오고 **노란색
  강조**로 표시됩니다.
- **맵에서 노드 클릭** → 아웃라인이 그 줄로 자동으로 스크롤됩니다.
- **아웃라인을 여는 순간**(분할·전체 모드 모두) 문서 처음이 아니라
  **맵에서 보던 위치**부터 보여줍니다 — 선택한 노드가 있으면 그 줄로,
  없으면 맵 화면 중앙에 가장 가까운 노드의 줄로 이동합니다. 큰 맵을
  확대해 보다가 전환해도 스크롤로 다시 찾아갈 필요가 없습니다.

## 아웃라인 모드 / 맵 모드 전환

상단 툴바(다크 모드 아이콘 옆)의 **모드 토글**을 누르면 편집 화면
**전체**가 아웃라인 전용 ↔ 맵 전용으로 바뀝니다(분할이 아니라 통째로
전환). 버튼은 지금 갈 수 있는 곳을 보여 줍니다 — 맵 모드에서는
**목록(불릿) 아이콘**, 아웃라인 모드에서는 **마인드맵(노드) 아이콘**.
아웃라인 전체에서 ✕(또는 같은 아이콘)을 누르면 맵으로 돌아옵니다.

**맵으로 돌아오면 떠나기 전의 줌·위치가 그대로**입니다 — 맵 전체
맞추기 후 100% 보기로 바꿔 두고 아웃라인에 다녀와도 100% 화면 그대로
이어서 봅니다 (Kanban에 다녀올 때도 동일).

> **분할 보기가 켜져 있으면 이 토글은 비활성**입니다(분할이 이미
> 아웃라인+맵이라). 분할을 닫은 뒤 전환하세요.

**HTML 뷰어에도 같은 버튼이 있습니다** — 헤더의 **◫(분할)** 과
**모드 토글(목록↔마인드맵 아이콘, 전체 아웃라인/맵)**. 뷰어 아웃라인은
읽기 전용이며, 줄을 클릭하면 맵에서 그 노드가 중앙에 노란색으로
강조됩니다.
