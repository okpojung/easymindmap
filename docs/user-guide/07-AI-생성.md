# 07. AI로 맵 생성

질문을 입력하면 AI가 답을 만들어 **그대로 마인드맵으로** 변환해 줍니다.
방법은 두 가지입니다 — 왼쪽 속성의 `AI` 탭 상단에서 전환합니다:

| 모드 | 필요한 것 | 어울리는 분 |
|---|---|---|
| **🌐 웹 AI (키 불필요)** | Claude·ChatGPT·Gemini 등 **웹 구독**(또는 무료 웹) | API 키 발급이 부담스러운 대부분의 사용자 — **기본 모드** |
| **🔑 API 키** | 각 AI 회사의 API 키 (별도 과금) | 앱 안에서 버튼 한 번으로 끝내고 싶은 분 |

> API 키를 등록하지 않았다면 **웹 AI가 기본**으로 열립니다(키를
> 등록하면 API 키 모드가 기본).

## 🌐 웹 AI 모드 — API 키 없이 (기본)

쓰고 있는 AI 웹 채팅(Claude, ChatGPT, Gemini, 무엇이든)으로 맵을
만듭니다. **복사 2번**이면 됩니다:

1. `AI` 탭 → 🌐 웹 AI → **① 무엇을 만들까요?** 에 주제 입력
   (예: "신제품 출시 계획을 마인드맵으로 정리해줘")
2. **`📋 ① 프롬프트 복사`** — 맵 변환 규칙(EMM 템플릿)과 주제가 함께
   클립보드에 담깁니다. 아래 [Claude] [ChatGPT] [Gemini] 버튼을 누르면
   AI 창이 새 탭으로 열리면서 **질문까지 자동 입력**됩니다(주제를 먼저
   적어 두세요). Gemini만 자동 입력을 지원하지 않아 Ctrl+V로 붙여넣으면
   됩니다 — 어느 쪽이든 클립보드에도 복사해 둡니다.
3. AI 채팅창에 **붙여넣고(Ctrl+V) 실행** → 답변이 코드블록 하나로
   나옵니다 → 블록 우상단 **복사 버튼** 클릭.
4. EasyMindMap의 **③ 답변 붙여넣기** 칸에 Ctrl+V — 붙여넣기만으로는
   **아무 것도 바뀌지 않습니다.** "'제목' · N노드 인식됨" 안내가 뜨면,
   아래에서 반영할 방법을 **직접 고르세요**:
   - **`③ 새 맵 생성`** — 답변을 새 맵으로 엽니다.
   - **`선택 노드에 삽입`** — 맵에서 고른 노드의 하위로 추가합니다.
     (노드를 고르지 않고 누르면 먼저 노드를 선택하라고 알려 줍니다.)

   어느 쪽을 누르든 **패널 오른쪽 옆(화면 세로 중앙)에 확인 창**이
   떠서 [확인]을 눌러야 진행됩니다. 되돌리려면 Ctrl+Z.

- 답변을 복사할 때는 **답변 끝의 ⧉ 복사 버튼**을 쓰세요 — 화면을 드래그해 복사하면 코드·도식 블록이 깨집니다. 답변은 **`~~~`(물결 3개) 코드블록** 하나로 오도록 요청됩니다 —
  백틱(```)으로 나오면 `⧉ 재요청 문구 복사`를 쓰세요.
- 답변이 코드블록 없이 나오거나 형식이 어긋나면 빨간 안내와 함께
  **`⧉ 재요청 문구 복사`** 버튼이 나타납니다 — AI 창에 붙여넣으면
  올바른 형식으로 다시 출력해 줍니다.
- 입력한 내용과 답변은 **EasyMindMap 서버로 전송되지 않습니다.**
- Guest 체험 중에는 이 **웹 AI 모드만** 열립니다(API 키 등록·호출은
  가입 후).

### 더 편하게 ① — ChatGPT 사용자: 'EasyMindMap Copilot'

바로가기 줄 아래의 **`⚡ EasyMindMap Copilot GPT`** 버튼은 [ChatGPT]
(일반 채팅)와 **다른 것**입니다 — 우리가 공개한 전용 GPT로, 맵 변환
규칙이 GPT 안에 이미 들어 있습니다. 그래서 **① 프롬프트 없이 주제만**
자동 입력되고, 그대로 코드블록 답변이 나옵니다 (ChatGPT 로그인 필요).
(답변 복사 → ③칸 붙여넣기만 하면 끝 — 복사 1번)

### 더 편하게 ② — Claude 사용자: '프로젝트'에 지침 넣기

Claude에는 커스텀 GPT 대신 **프로젝트(Projects)** 가 있습니다.
프로젝트마다 **지침(Instructions)을 미리 심어둘 수 있어서**, 그 안에서
대화하면 Claude가 매번 지침을 자동으로 읽고 답합니다 — 맵 변환 규칙을
한 번만 넣어두면 이후로는 **주제만 입력**하면 됩니다.

**만들기 (한 번만, 약 2분 — Claude Pro 권장):**

1. claude.ai → 왼쪽 메뉴 **프로젝트(Projects)** → **+ 새 프로젝트**
2. 이름: `EasyMindMap Copilot` → 만들기
3. 프로젝트 화면의 **지침 설정(Set project instructions)** 클릭
4. 개발 문서 `docs/04-extensions/ai/easymindmap-copilot-gpt.md` §2의
   **'지침' 블록 전문**을 붙여넣고 저장

**사용하기 (매번):**

1. **그 프로젝트 안에서** 새 대화 시작 — 프로젝트 밖 일반 대화에는
   지침이 적용되지 않습니다 (가장 자주 헷갈리는 부분!)
2. 주제만 입력 → 코드블록 답변 → 복사 → EasyMindMap ③칸에 붙여넣기

**Claude 프로젝트만의 활용법:**

- **프로젝트 지식(Knowledge)** 에 PDF·문서를 올려두면 그 내용을
  참고해 맵을 만듭니다 — 예: 사업계획서를 올리고 "이 문서 기반으로
  출시 로드맵 마인드맵 만들어줘".
- 맵 생성 대화가 프로젝트 폴더에 모여서 "지난번 그 맵 이어서
  확장해줘"처럼 이어가기 좋습니다.
- "3장을 더 자세히 늘려줘" 같은 후속 요청에도 수정된 전체가 다시
  코드블록으로 나옵니다 — 복사해 다시 붙여넣으면 됩니다.

**세 가지 방법 비교:**

| | 일반 AI + 프롬프트 복사 | ChatGPT Copilot GPT | Claude 프로젝트 |
|---|---|---|---|
| 매번 할 일 | 복사 2번 | **복사 1번** | **복사 1번** |
| 쓸 수 있는 AI | 전부 | ChatGPT 전용 | Claude 전용 |
| 사전 준비 | 없음 | 없음 (공개 GPT) | 내 계정에 1회 생성 |
| 규칙 갱신 시 | 자동 (앱이 최신 복사) | 자동 (우리가 교체) | 지침 재붙여넣기 |

### 웹 AI로 선택 노드 확장

1. 맵에서 노드 클릭 → 웹 AI 패널 아래 **`📋 확장 프롬프트 복사`**
2. AI 창에 붙여넣고 실행 → 답변 복사
3. **③칸에 붙여넣고** → **`선택 노드에 삽입`** — 그 노드의 하위로
   채워집니다 (`Ctrl+Z`로 되돌리기 가능)

## 🔑 API 키 모드

앱 안에서 버튼 한 번으로 생성까지 끝나는 방식입니다.

### 준비 — API 키 등록 (처음 한 번)

> **중요**: AI 사용료는 각 회사의 **API 요금**으로 별도 과금됩니다.
> ChatGPT Plus·Claude Pro·Google AI Pro 같은 **구독 요금제와는 별개**입니다
> (Gemini만 결제 없이 쓸 수 있는 무료 사용량 제공). 구독만 있다면
> 위의 **웹 AI 모드**를 쓰세요.

1. `AI` 탭 → **`AI 설정`**.
2. 사용할 회사의 칸에 API 키를 붙여넣습니다.
3. 각 회사 칸의 **"키 발급 방법 (처음이신가요?)"** 을 펼치면 발급
   페이지 주소와 단계별 안내가 나옵니다.

#### 모델·우선순위 설정

- **모델**: 회사별로 기본 모델이 정해져 있고, 목록에서 바꾸거나 직접
  입력할 수 있습니다.
  - Gemini는 구글이 모델을 자주 바꾸므로, 오류가 나면 **"↻ 지금 키로
    사용 가능한 모델 불러오기"** 를 눌러 현재 쓸 수 있는 모델을 고릅니다.
- **우선순위**: 키를 여러 개 등록했을 때 어떤 AI를 먼저 쓸지 순서를
  `▲▼`로 정합니다. 생성 화면의 **'자동'** 은 이 순서대로 씁니다.

### 맵 만들기

1. `AI` 탭 → 🔑 API 키 모드.
2. 질문을 입력합니다 (예: "우분투 22.04에 워드프레스 설치 방법을 초보자
   수준으로 알려줘").
3. **`AI로 맵 생성`** → 잠시 후 답변이 맵으로 바뀝니다.
4. 현재 맵을 닫는다는 확인이 나옵니다 (`Ctrl+Z`로 복구 가능).

### 선택 노드 자세히 확장

이미 만든 맵(AI 생성이든 직접 만든 것이든)에서 **특정 노드를 더 깊게**
파고들 때 씁니다.

1. 맵에서 확장할 **노드를 클릭**합니다.
2. `AI` 탭 아래 **"선택 노드 자세히 확장"** 에 대상이 표시됩니다.
3. **`선택 노드 자세히 확장`** 버튼을 누릅니다.
4. AI가 **중심 주제(프로젝트 지침) + 그 노드까지의 상위 경로 + 이 노드**를
   보고, 세부 내용을 **그 노드의 하위 노드로** 채웁니다 (확인 후 추가,
   `Ctrl+Z`로 되돌리기 가능).

> 중심 주제 아래에 이름에 **`@소스`** 가 들어간 2레벨 노드를 만들어
> 참고 내용을 적어 두면, 확장할 때 그 소스도 함께 참고합니다.
> (웹 AI 모드의 확장 프롬프트에도 같은 규칙이 적용됩니다.)
