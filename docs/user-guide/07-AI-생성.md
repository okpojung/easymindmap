# 07. AI로 맵 생성

질문을 입력하면 AI(Anthropic Claude / OpenAI ChatGPT / Google Gemini)가
답을 만들어 **그대로 마인드맵으로** 변환해 줍니다.

## 준비 — API 키 등록 (처음 한 번)

> **중요**: AI 사용료는 각 회사의 **API 요금**으로 별도 과금됩니다.
> ChatGPT Plus·Claude Pro·Google AI Pro 같은 **구독 요금제와는 별개**입니다
> (Gemini만 결제 없이 쓸 수 있는 무료 사용량 제공).

1. 상단 **`AI 생성`** 버튼 → **`설정`** 탭.
2. 사용할 회사의 칸에 API 키를 붙여넣습니다.
3. 각 회사 칸의 **"키 발급 방법 (처음이신가요?)"** 을 펼치면 발급
   페이지 주소와 단계별 안내가 나옵니다.

### 모델·우선순위 설정

- **모델**: 회사별로 기본 모델이 정해져 있고, 목록에서 바꾸거나 직접
  입력할 수 있습니다.
  - Gemini는 구글이 모델을 자주 바꾸므로, 오류가 나면 **"↻ 지금 키로
    사용 가능한 모델 불러오기"** 를 눌러 현재 쓸 수 있는 모델을 고릅니다.
- **우선순위**: 키를 여러 개 등록했을 때 어떤 AI를 먼저 쓸지 순서를
  `▲▼`로 정합니다. 생성 화면의 **'자동'** 은 이 순서대로 씁니다.

## 맵 만들기

1. `AI 생성` → **`생성`** 탭.
2. 질문을 입력합니다 (예: "우분투 22.04에 워드프레스 설치 방법을 초보자
   수준으로 알려줘").
3. **`AI로 맵 생성`** → 잠시 후 답변이 맵으로 바뀝니다.
4. 현재 맵을 닫는다는 확인이 나옵니다 (`Ctrl+Z`로 복구 가능).

## 선택 노드 자세히 확장

이미 만든 맵(AI 생성이든 직접 만든 것이든)에서 **특정 노드를 더 깊게**
파고들 때 씁니다.

1. 맵에서 확장할 **노드를 클릭**합니다.
2. `AI 생성` 탭 아래 **"선택 노드 자세히 확장"** 에 대상이 표시됩니다.
3. **`선택 노드 자세히 확장`** 버튼을 누릅니다.
4. AI가 **중심 주제(프로젝트 지침) + 그 노드까지의 상위 경로 + 이 노드**를
   보고, 세부 내용을 **그 노드의 하위 노드로** 채웁니다 (확인 후 추가,
   `Ctrl+Z`로 되돌리기 가능).

> 중심 주제 아래에 이름에 **`@소스`** 가 들어간 2레벨 노드를 만들어
> 참고 내용을 적어 두면, 확장할 때 그 소스도 함께 참고합니다.
