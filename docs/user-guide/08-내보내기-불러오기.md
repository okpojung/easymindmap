# 08. 내보내기 · 불러오기

## 내보내기

상단 **`내보내기`** 버튼을 누르면 두 가지가 있습니다.

| 형식 | 쓰임 |
|---|---|
| **HTML 파일** | 읽기 전용 **뷰어** — 브라우저로 열어 보고, 다시 불러올 수도 있음 |
| **MD 파일** | 일반 편집기에서 수정 가능한 Markdown — 다시 불러올 수도 있음 |

> 사진·첨부가 있으면 **MD·HTML 어느 쪽이든 자동으로 ZIP**으로 내려갑니다
> — 안에는 맵 파일 하나와 `files/` 폴더(첨부 원본)가 들어 있습니다.
> 그래서 ZIP은 **두 종류**입니다: `제목.md + files/…` 를 담은 MD ZIP,
> `제목.html + files/…` 를 담은 HTML ZIP. 불러올 때는 **ZIP 파일
> 불러오기** 하나로 둘 다 열립니다(안의 맵 파일을 알아서 찾습니다).
> 첨부가 없으면 ZIP 없이 `.md` / `.html` 파일 하나로 내려갑니다.

> Guest 체험 중에는 서버 저장이 막히고 내보내기(MD·HTML)로만 파일을
> 보관할 수 있습니다.

> **첨부 파일과 저장** — 2MB 이하 첨부는 맵 문서 안에 함께 저장되고
> (한 맵에 내장되는 합계는 10MB까지 — 넘으면 로그인 상태에서 자동으로
> 서버 저장소에 올라갑니다),
> 2MB를 넘는 첨부는 **로그인 상태면 서버 첨부 저장소에 올라갑니다** —
> 둘 다 저장했다가 나중에 다시 열어도 내보내기 ZIP에 그대로 담깁니다.
> 저장 용량(문서+첨부 합산, 무료 1GB)은 우상단 계정 메뉴에서 확인할 수
> 있고, 한도를 넘으면 업로드·저장 시 안내가 뜹니다. 로그인하지 않은
> 상태의 2MB 초과 첨부만 그 창에서만 유효합니다("원본을 찾을 수 없어
> 제외" 안내 후 다시 첨부하면 포함).

### MD로 저장하면 이렇게 생겼습니다

- 노드 안의 **표·코드·체크리스트는 한 줄로 뭉개지지 않고** 진짜
  Markdown 블록으로 저장됩니다 — 표는 여러 줄 파이프 표(`| 셀 | 셀 |` +
  구분선), 코드는 ``` 펜스, 체크는 `- [x]`. 표 아래에 이어 쓴 글
  ("※ 첨부 …" 등)도 표 **뒤에 원문 순서 그대로** 남습니다.
- **노트(문단·코드·표·체크)도 모두 Markdown 형식**으로 함께
  저장됩니다 — 문단 노트는 인용문(`>`), 코드 노트는 펜스, 표 노트는
  파이프 표. 일반 편집기·다른 앱에서도 그대로 읽힙니다.
- 노드의 링크는 `🔗 [라벨](주소)`, 사진은 `![…](files/…)` 로
  저장되고, 다시 불러오면 원래의 링크·사진으로 돌아옵니다.

## HTML 뷰어 사용법

내보낸 HTML을 브라우저로 열면, 편집은 못 해도 **에디터와 거의 같은
조작**을 할 수 있습니다:

- **검색** (헤더 검색창)
- **줌** (우하단 −/NN%/+/100% 보기)
- **접기/펼치기** (모두 펼치기 `+` / 모두 접기 `−`, 노드별 토글)
- **Pan**(손 아이콘 또는 마우스 오른쪽 드래그), **화면 맞추기**,
  **선택 노드 중앙 보기**, **전체화면**, **다크 모드**
- **아웃라인 분할**(◫) — 왼쪽에 글 목록, 오른쪽에 맵. 목록의 줄을
  클릭하면 맵에서 그 노드가 중앙에 노란색으로 강조됩니다(읽기 전용).
- **아웃라인 모드 / 맵 모드 전환**(목록↔마인드맵 아이콘) — 화면
  **전체**를 아웃라인 전용 ↔ 맵 전용으로 통째 전환. 버튼은 지금 갈 곳을
  보여 줍니다(맵일 때 목록 아이콘, 아웃라인일 때 마인드맵 아이콘).
  분할 보기가 켜져 있으면 이 버튼은 비활성입니다.

> 에디터의 아웃라인 분할·모드 전환과 같은 조작을 뷰어에서도 그대로
> 쓸 수 있습니다.

## 클라우드 문서 (로그인 후)

로그인하면 맵이 **내 계정에 저장**되어 어느 기기에서나 이어서 쓸 수
있습니다.

| 어디에 | 메뉴 | 하는 일 |
|---|---|---|
| 상단 툴바 | **내 문서** | **문서함**을 엽니다 (폴더 이동·정렬·이름 변경·삭제). ※ 로그인 전/개발 모드에서는 왼쪽 `+ 새 맵 > ☁ 서버 맵 불러오기`에도 같은 항목이 있습니다 |
| 상단 툴바 | **☁ 저장** | 지금 내용을 서버에 저장합니다 (이 시점이 히스토리 버전으로 남습니다) |
| 상단 툴바 | **⧉ 다른 이름으로 저장** | 지금 내용을 새 폴더·이름의 **새 맵**으로 저장하고, 이 탭은 그 새 맵을 편집합니다 (기본 이름 `제목 사본`) |
| 상단 툴바 | **✕ 맵 닫기** | 지금 맵을 **저장하고 닫은 뒤** 문서함을 보여줍니다 |

편집 중에는 **자동으로도 저장**되므로 평소에는 따로 누르지 않아도
됩니다. **☁ 저장**은 "이 시점으로 돌아올 수 있게 표시해 두는" 버튼이라고
생각하면 됩니다. **고친 내용이 없으면** 저장을 건너뛰고 "변경된 내용이
없어 그대로 두었습니다"라고 알려 이력이 불어나지 않습니다.

### 처음 저장할 때 — 폴더와 이름을 정합니다

새로 만든 맵의 제목은 그냥 **"새 맵"**입니다. 편집을 마치고 **☁ 저장**을
누르면 그때 물어봅니다:

- **저장 위치** — 폴더를 고르거나, 그 자리에서 **새 폴더**를 만듭니다.
- **맵 이름** — 파일 이름에 해당합니다.

맵은 모두 **단독맵**으로 만들어집니다. 협업맵은 나중에 협업자를
초대해 승인·참여하면 자동으로 전환됩니다(협업 기능은 준비 중).

같은 폴더에 **같은 이름의 맵이 이미 있으면** "이미 있습니다"라고 알려
줍니다 — 이름을 바꾸거나 다른 폴더를 고르면 됩니다.

한 번 저장한 뒤에는 **묻지 않고 그 이름으로** 저장됩니다. 맵 안의 중심
주제를 바꿔도 **맵 이름은 그대로**입니다(이름은 문서함에서 ✏로 바꿉니다).

### 맵 닫기

- 이미 저장한 맵이면 **마지막 내용을 저장한 뒤** 닫습니다. 저장에
  실패하면 **닫지 않고** 알려주므로 내용이 사라지지 않습니다.
- 아직 한 번도 저장하지 않은 맵(새 맵·불러온 파일)이면
  **"⚠ 맵이 저장되지 않았습니다"**라고 먼저 알려 줍니다 —
  *저장하고 닫기 / 저장 없이 닫기 / 취소* 중에서 고르면 됩니다.
- 실수로 닫았어도 **Ctrl+Z**로 문서가 되돌아옵니다.
- 닫은 뒤에는 문서함이 열립니다.

### 문서함 (내 문서)

상단 툴바 **내 문서**로 문서함을 엽니다 (폴더 이동·정렬·이름 변경·
삭제) — 편집 화면 자리에 열립니다(팝업 창이 아닙니다).
※ 로그인 전/개발 모드에서는 왼쪽 `+ 새 맵 > ☁ 서버 맵 불러오기`에도
같은 항목이 있습니다.

- **홈 > 폴더** 경로를 눌러 위아래로 이동합니다.
- **＋ 새 폴더**로 지금 위치에 폴더를 만듭니다.
- 목록에는 맵마다 **생성일 · 수정일 · 노드 수 · 크기(KB/MB/GB) ·
  첨부 수 · 첨부 용량**이 보입니다. 열 제목(**이름 / 생성일 / 수정일 /
  노드 / 크기 / 첨부 / 첨부 용량**)을 누르면 그 열로 정렬되고, 다시
  누르면 **오름차순↔내림차순**이 바뀝니다.
- 노드 수·첨부 통계가 **'—'** 로 보이는 맵은 이 기능이 생기기 전에
  저장된 것입니다 — 한 번 열어서 저장하면 채워집니다.
- 각 줄 오른쪽 **관리** 칸의 버튼 3개 — ✎ 연필(이름 변경) ·
  폴더+화살표(다른 폴더로 이동) · 휴지통(삭제). 버튼에 마우스를 올리면
  이름이 나옵니다.
- 폴더는 **비어 있을 때만** 지울 수 있습니다 — 안에 맵이 남아 있으면
  몇 개가 남았는지 알려 줍니다.
- 맵 유형 배지(👤 단독맵 / 👥 협업맵)는 **표시**입니다 — 협업맵은
  협업자를 초대해 승인·참여하면 자동으로 바뀝니다(협업 기능 준비 중).
- 지금 편집 중인 맵을 목록에서 누르면 문서함이 닫히고 **편집 화면으로
  돌아갑니다**.

### 다른 맵은 새 탭에서 열립니다

편집 중인 맵이 있는 상태에서 다른 맵을 고르면, 지금 보던 맵을 밀어내지
않고 **브라우저 새 탭**에서 열립니다(주소에 `?map=…`이 붙습니다).
맵을 닫은 직후처럼 **열려 있는 맵이 없을 때만** 지금 탭에 그대로
불러옵니다.

- 새 탭이 열리지 않으면 브라우저의 **팝업 차단**을 해제해 주세요.
- 이미 이 탭에서 보고 있는 맵을 다시 고르면 새 탭을 만들지 않습니다.
- 여러 맵을 동시에 편집하려면 탭을 여러 개 열면 됩니다 — 몇 개까지라는
  제한은 없습니다(브라우저가 감당하는 만큼).

저장할 맵이 없을 때(막 로그인했거나 맵을 닫은 직후) **☁ 저장**과
**✕ 맵 닫기**는 "열려 있는 맵이 없습니다"라고만 알립니다.

레이아웃도 함께 저장됩니다 — 진행트리로 편집해 저장했다면, 어느
기기에서 다시 열어도 진행트리로 열립니다.

### 저장 버전 이력 (히스토리)

왼쪽 **히스토리** 패널에 **저장할 때마다 그 시점이 버전으로** 쌓입니다.

- 쌓이는 시점: **☁ 저장**과 **맵 닫기** (편집 중 자동저장은 쌓이지
  않습니다 — 이력이 지저분해지고 용량이 커지므로). **고친 내용이
  없으면** 저장을 건너뛰고 "변경된 내용이 없어 그대로 두었습니다"라고
  알려 이력이 불어나지 않습니다.
- 각 줄에 **저장한 날짜·시간**, **v버전 번호와 제목**, 그리고
  **레이아웃 · 노드 수 · 문서 크기 · 첨부 N개·용량**이 보입니다.
- **"새 탭으로"** 를 누르면 그 시점 내용이 **새 문서**
  (`원래제목_history_날짜_시각`)로 만들어져 **브라우저 새 탭**에서
  열립니다 — **지금 편집 중인 맵은 그대로** 두므로 안심하고 과거 시점을
  확인할 수 있습니다.

> **되돌리기(Ctrl+Z)와는 다릅니다** — 되돌리기는 지금 편집 중인 화면을
> 한 단계씩 되돌리는 기능(이 세션 안에서 99단계)이고, 히스토리는
> 저장 시점들을 **영구 보관**하는 기능입니다.

### 다른 곳에서 편집 중인 맵

같은 맵을 다른 브라우저/탭이 편집 중이면 **읽기 전용**으로 열리고
상단에 `🔒 읽기 전용 — 다른 세션에서 편집 중` 배너가 뜹니다. 고친
내용은 그 맵에 저장되지 않으며, 남기려면 **⧉ 다른 이름으로 저장**으로
사본을 만드세요. 닫을 때는 저장 없이 닫힙니다.

## 불러오기

왼쪽 **`+ 새 맵`** → "Local 파일 불러오기":

| 버튼 | 지원 파일 |
|---|---|
| **MD 파일 불러오기** | 일반 Markdown + EasyMindMap이 만든 MD |
| **HTML 파일 불러오기** | EasyMindMap이 만든 HTML만 — 일반 웹페이지 HTML을 고르면 **"EasyMindMap 뷰어 HTML이 아닙니다"** 라고 빨간 안내가 뜹니다 |
| **ZIP 파일 불러오기** | EasyMindMap HTML/MD + files/ 첨부 포함 |

### MD 블록 배치 옵션

일반 MD를 불러올 때 문단·코드·표·체크리스트를 어디에 둘지 고를 수
있습니다 (버튼 위 옵션, 선택은 기억됩니다):

- **노드로 (기본)**: 경계가 확실한 블록(코드·표·이미지)은 **각각의
  자식 노드**로 분리됩니다 — markmap 등 다른 마인드맵과 같은 모양으로,
  코드는 코드 노드, 표는 격자 노드, 이미지는 사진 노드가 문서 순서
  그대로 형제로 놓입니다. 표 바로 아래의 인용문("※ 첨부 …")은 표
  노드에 함께 담깁니다.
- **노트로**: 예전 방식 — 블록이 노드의 노트(📝 아이콘)로 들어갑니다.

> **분리 vs 한 덩어리** — MD 문서처럼 빈 줄로 나뉜 독립 블록은 각각의
> 노드로 변환하지만, **웹 기사·결재 문서를 붙여넣을 때**처럼 글
> 중간에 사진·표가 섞인 내용은 **한 노드**에 원문 순서 그대로
> 담깁니다. 이것이 EasyMindMap의 상호 변환 기본 원칙입니다.

EasyMindMap이 내보낸 MD(메타데이터 포함)는 이 옵션과 무관하게 원본
그대로 복원됩니다.

### 문서 속 하이퍼링크는 이렇게 변환됩니다

- **노드가 되는 글** 속 `[라벨](주소)` → 노드에는 **라벨만** 깔끔하게
  남고, 주소는 노드의 **🔗 아이콘**으로 첨부됩니다 (하나면 클릭 즉시
  열기, 여러 개면 목록에서 선택).
- **노트가 되는 글** 속 링크 → **원문 그대로** 보존되어 노트 창에서
  바로 클릭해 열 수 있습니다.
- **중심 노드는 제목만** 담습니다 — 문서 첫머리의 작성 정보·머리말은
  중심 노드의 노트로 첨부되어 중심이 지저분해지지 않습니다.

### 문서 속 이미지 URL은 사진으로 내려받습니다

- `![](https://…png)` 같은 **이미지 주소는 자동으로 다운로드해 맵에
  내장**합니다 (markmap 등 다른 앱의 MD도 사진이 살아납니다). 한 줄
  전체가 이미지 주소여도 똑같이 사진이 됩니다.
