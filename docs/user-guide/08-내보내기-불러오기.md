# 08. 내보내기 · 불러오기

## 내보내기

상단 **`내보내기`** 버튼을 누르면 두 가지가 있습니다.

| 형식 | 쓰임 |
|---|---|
| **HTML 파일** | 읽기 전용 **뷰어** — 브라우저로 열어 보고, 다시 불러올 수도 있음 |
| **MD 파일** | 일반 편집기에서 수정 가능한 Markdown — 다시 불러올 수도 있음 |

> 사진·첨부가 있으면 자동으로 **ZIP**(파일 + files/ 폴더)으로 내려갑니다.

### MD로 저장하면 이렇게 생겼습니다

- 노드 안의 **표·코드·체크리스트는 한 줄로 뭉개지지 않고** 진짜
  Markdown 블록으로 저장됩니다 — 표는 여러 줄 파이프 표(`| 셀 | 셀 |` +
  구분선), 코드는 ``` 펜스, 체크는 `- [x]`. 표 아래에 이어 쓴 글
  ("※ 첨부 …" 등)도 표 **뒤에 원문 순서 그대로** 남습니다.
- **노트(문단·코드·표·체크)도 모두 Markdown 형식**으로 함께
  저장됩니다 — 문단 노트는 인용문(`>`), 코드 노트는 펜스, 표 노트는
  파이프 표. 일반 편집기·다른 앱에서도 그대로 읽힙니다.
- 노드의 링크는 `🔗 [라벨](주소)`, 사진은 `![…](files/…)` 로
  저장되고, 다시 불러오면 원래의 링크·사진으로 돌아옵니다.

## HTML 뷰어 사용법

내보낸 HTML을 브라우저로 열면, 편집은 못 해도 **에디터와 거의 같은
조작**을 할 수 있습니다:

- **검색** (헤더 검색창)
- **줌** (우하단 −/NN%/+/100% 보기)
- **접기/펼치기** (모두 펼치기 `+` / 모두 접기 `−`, 노드별 토글)
- **Pan**(손 아이콘 또는 마우스 오른쪽 드래그), **화면 맞추기**,
  **선택 노드 중앙 보기**, **전체화면**, **다크 모드**
- **아웃라인 분할**(◫) — 왼쪽에 글 목록, 오른쪽에 맵. 목록의 줄을
  클릭하면 맵에서 그 노드가 중앙에 노란색으로 강조됩니다(읽기 전용).
- **아웃라인 모드 / 맵 모드 전환**(목록↔마인드맵 아이콘) — 화면
  **전체**를 아웃라인 전용 ↔ 맵 전용으로 통째 전환. 버튼은 지금 갈 곳을
  보여 줍니다(맵일 때 목록 아이콘, 아웃라인일 때 마인드맵 아이콘).
  분할 보기가 켜져 있으면 이 버튼은 비활성입니다.

> 에디터의 아웃라인 분할·모드 전환과 같은 조작을 뷰어에서도 그대로
> 쓸 수 있습니다.

## 불러오기

왼쪽 **`+ 새 맵`** → "Local 파일 불러오기":

| 버튼 | 지원 파일 |
|---|---|
| **MD 파일 불러오기** | 일반 Markdown + EasyMindMap이 만든 MD |
| **HTML 파일 불러오기** | EasyMindMap이 만든 HTML만 |
| **ZIP 파일 불러오기** | EasyMindMap HTML/MD + files/ 첨부 포함 |

### MD 블록 배치 옵션

일반 MD를 불러올 때 문단·코드·표·체크리스트를 어디에 둘지 고를 수
있습니다 (버튼 위 옵션, 선택은 기억됩니다):

- **노드로 (기본)**: 경계가 확실한 블록(코드·표·이미지)은 **각각의
  자식 노드**로 분리됩니다 — markmap 등 다른 마인드맵과 같은 모양으로,
  코드는 코드 노드, 표는 격자 노드, 이미지는 사진 노드가 문서 순서
  그대로 형제로 놓입니다. 표 바로 아래의 인용문("※ 첨부 …")은 표
  노드에 함께 담깁니다.
- **노트로**: 예전 방식 — 블록이 노드의 노트(📝 아이콘)로 들어갑니다.

> **분리 vs 한 덩어리** — MD 문서처럼 빈 줄로 나뉜 독립 블록은 각각의
> 노드로 변환하지만, **웹 기사·결재 문서를 붙여넣을 때**처럼 글
> 중간에 사진·표가 섞인 내용은 **한 노드**에 원문 순서 그대로
> 담깁니다. 이것이 EasyMindMap의 상호 변환 기본 원칙입니다.

EasyMindMap이 내보낸 MD(메타데이터 포함)는 이 옵션과 무관하게 원본
그대로 복원됩니다.

### 문서 속 하이퍼링크는 이렇게 변환됩니다

- **노드가 되는 글** 속 `[라벨](주소)` → 노드에는 **라벨만** 깔끔하게
  남고, 주소는 노드의 **🔗 아이콘**으로 첨부됩니다 (하나면 클릭 즉시
  열기, 여러 개면 목록에서 선택).
- **노트가 되는 글** 속 링크 → **원문 그대로** 보존되어 노트 창에서
  바로 클릭해 열 수 있습니다.
- **중심 노드는 제목만** 담습니다 — 문서 첫머리의 작성 정보·머리말은
  중심 노드의 노트로 첨부되어 중심이 지저분해지지 않습니다.

### 문서 속 이미지 URL은 사진으로 내려받습니다

- `![](https://…png)` 같은 **이미지 주소는 자동으로 다운로드해 맵에
  내장**합니다 (markmap 등 다른 앱의 MD도 사진이 살아납니다). 한 줄
  전체가 이미지 주소여도 똑같이 사진이 됩니다.
- 원본 사이트가 다운로드를 막으면(CORS) 화면에는 보이되 주소 참조로
  남고, 그마저 안 되면 **🔗 링크로 대체**되어 주소를 잃지 않습니다 —
  불러온 뒤 안내 문구로 몇 개를 내장/대체했는지 알려줍니다.
- 서버 저장과 연결되면 이미지·첨부를 서버에 올리고 MD 변환 시 서버
  경로로 바꾸는 방식을 지원할 예정입니다.

- 일반 Markdown은 제목(#)·목록(-) 구조를 맵으로 바꿔 줍니다.
- EasyMindMap이 만든 파일은 스타일·노트·사진·태그까지 원래대로
  복원됩니다 (파일에 숨은 메타데이터 덕분).
