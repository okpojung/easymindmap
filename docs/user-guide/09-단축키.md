# 09. 단축키

> 전체·정식 목록은 개발 문서
> `docs/03-editor-core/search/17-keyboard-shortcuts.md`에 있습니다. 아래는
> 자주 쓰는 것만 추린 사용자용 요약입니다.

## 노드 편집

| 단축키 | 기능 |
|---|---|
| `Space` | 자식 노드 추가 |
| `Shift+Space` | 아래 형제 노드 추가 |
| `Tab` (편집 끝낸 뒤) | 자식 노드 추가 |
| `F2` / 더블클릭 | 글자 편집 시작 |
| `Enter` (편집 중) | 줄바꿈 |
| `Esc` | 편집 끝내기 / 선택 해제 |
| `Delete` / `Backspace` | 노드 삭제 |
| `Ctrl+D` | 노드 복제 |
| `Ctrl+C` / `Ctrl+V` | 복사 / 붙여넣기 |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | (편집 중) 굵게 / 기울임 / 밑줄 |

## 선택 · 이동

| 단축키 | 기능 |
|---|---|
| 클릭 | 단일 선택 |
| `Ctrl+클릭` | 다중 선택 토글 |
| `Shift+클릭` | 범위 선택 |
| `↑ ↓ ← →` | 인접 노드로 선택 이동 |

## 화면(캔버스)

| 단축키 | 기능 |
|---|---|
| `Ctrl + =` / `Ctrl + -` | 확대 / 축소 |
| `Ctrl + 0` | 100% 보기 |
| `Ctrl + 마우스 휠` | 커서 기준 확대/축소 |
| `H` | Pan(손) 모드 전환 |
| 마우스 오른쪽 드래그 | 임시 화면 이동 |
| `Ctrl + Z` / `Ctrl + Y` | 되돌리기 / 다시 실행 |
