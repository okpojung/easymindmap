# 09. 단축키

> 전체·정식 목록은 개발 문서
> `docs/03-editor-core/search/17-keyboard-shortcuts.md`에 있습니다. 아래는
> 자주 쓰는 것만 추린 사용자용 요약입니다.

## 노드 편집

| 단축키 | 기능 |
|---|---|
| `Space` | 자식 노드 추가 |
| `Shift+Space` | 아래 형제 노드 추가 |
| `Tab` (편집 끝낸 뒤) | 자식 노드 추가 |
| `Ctrl+Space` | 여러 노드 한 번에 추가 |
| 더블클릭 | 글자 편집 시작 (아웃라인 화면은 `Enter`·`F2`) |
| `Enter` (편집 중) | 저장하고 편집 끝내기 |
| `Shift+Enter` (편집 중) | 줄바꿈 |
| `Esc` | 편집 취소(고친 내용 버림) / 선택 해제 |
| `Delete` | 노드 삭제 |
| `Ctrl+C` / `Ctrl+V` | 선택 노드(하위 포함) 복사 / **선택한 노드의 하위로** 붙여넣기 |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | (편집 중) 굵게 / 기울임 / 밑줄 |

> 노드 복제는 `Ctrl+C` → 붙일 노드 선택 → `Ctrl+V`.

## 선택 · 이동

| 단축키 | 기능 |
|---|---|
| 클릭 | 단일 선택 |
| 빈 곳 드래그 | 러버밴드 다중 선택 (맵·Kanban 공통) |
| `Ctrl+←` | 상위(부모) 노드 추가 |

## 화면(캔버스)

| 단축키 | 기능 |
|---|---|
| `+` / `-` | 확대 / 축소 (5%씩) |
| `0` | 100% 보기 (화면 위치도 초기화) |
| `Ctrl + 마우스 휠` | 커서 기준 확대/축소 |
| `Alt+F` | 선택 노드 화면 중앙 보기 (다시 누르면 전체 보기) |
| `H` | Pan 모드 토글 (휠클릭·우클릭 드래그 = 임시 Pan) |
| `Delete` | 선택 노드/카드 삭제 — 러버밴드 다중 선택이면 **일괄 삭제** (맵·Kanban 공통, 되돌리기 1단계) |
| `Ctrl + Z` / `Ctrl + Y` | 되돌리기 / 다시 실행 (이 세션 안에서 최대 99단계) |

> 툴바의 되돌리기·다시 실행 버튼 사이 숫자가 **몇 단계 되돌렸는지**
> 보여 줍니다 — 최신 상태 = `0`, 한 번 되돌릴 때마다 `-1`, `-2`, …
> (다시 실행하면 줄고, 새 편집을 하면 그 지점이 새 원본 = `0`).
> 되돌리기는 **편집 세션 안에서만** 유효합니다 — 세션을 닫고 저장한
> 버전들의 이력(히스토리)은 서버 저장과 연결되면 왼쪽 '히스토리'
> 메뉴에서 제공됩니다.
