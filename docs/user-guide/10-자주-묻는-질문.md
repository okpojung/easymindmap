# 10. 자주 묻는 질문 (FAQ)

## AI

**Q. AI 생성이 "Gemini 호출 실패: 404 … no longer available"로 안 됩니다.**
구글이 그 모델을 없앤 것입니다. `AI 생성 → 설정 → Gemini 모델`에서
**"↻ 지금 키로 사용 가능한 모델 불러오기"** 를 눌러 현재 모델을 고르세요.

**Q. 제 ChatGPT/Claude 구독으로 API를 쓸 수 있나요?**
아니요. AI 사용료(API)는 구독과 **별개 요금**입니다. 각 회사 개발자
콘솔에서 API 키를 따로 발급받아야 합니다(키 발급 도움말 참고). Gemini만
결제 없이 쓸 수 있는 무료 사용량이 있습니다.

**Q. AI 답변이 웹 채팅보다 짧습니다.**
설정에서 더 큰 모델을 고르세요(예: OpenAI `gpt-4o`). 기본 프롬프트가
"웹 채팅처럼 상세하게"로 되어 있는지도 확인하세요.

## 내보내기 / 뷰어

**Q. 내보낸 HTML을 열고 "모두 접기"를 했더니 화면이 비어요.**
예전에 내보낸 파일의 문제로, 최신 버전에서 고쳐졌습니다. 앱을 최신으로
갱신하고 **맵을 다시 내보내기** 하면 새 파일부터 정상 동작합니다 (이미
받아둔 옛 파일은 계속 깨져 있습니다).

**Q. 사진이 있는 맵을 MD로 내보냈더니 ZIP으로 받아져요.**
정상입니다. 사진·첨부는 `files/` 폴더에 담아 ZIP으로 묶습니다. 다시
불러올 때 ZIP 그대로 넣으면 사진까지 복원됩니다.

## 붙여넣기 / 콘텐츠 보존

**Q. 붙여넣은 뉴스 기사가 나중에 삭제되면 내 맵의 사진도 사라지나요?**
대부분 **아닙니다**. EasyMindMap은 붙여넣는 순간 **글은 텍스트로,
사진은 다운로드해 맵 안에 내장**하므로 원본 기사가 삭제되거나
오프라인이어도 그대로 남습니다. 노드에 붙여넣든 노트에 붙여넣든
같습니다. 단, 일부 사이트(브라우저 보안 정책상 다운로드가 막힌 경우)나
아주 큰 이미지(2.5MB 초과)는 사진이 **링크로 남아** 원본이 사라지면 안
보일 수 있습니다. (자세히: `docs/04-extensions/content-permanence.md`)

**Q. 내보낸 HTML/ZIP 파일도 오프라인에서 사진이 보이나요?**
내장된 사진은 파일 안에 들어가므로 **오프라인·다른 컴퓨터에서도** 보입니다.
링크로 남은 사진만 온라인일 때 보입니다.

## 화면 / 조작

**Q. 맵 전체 맞추기를 했더니 너무 작게(6%) 보입니다.**
노드가 아주 많은 맵입니다. 오른쪽 위 **"모두 접기"** 로 2레벨만 남기면
구조를 한눈에 볼 수 있습니다.

**Q. 실수로 맵을 지웠어요 / 새 맵으로 바뀌었어요.**
`Ctrl + Z`(되돌리기)로 복구됩니다. 되돌리기·다시 실행 버튼 사이
숫자(0/-1/-2…)가 몇 단계 되돌렸는지 보여 줍니다 (세션 안 최대 99단계).

**Q. 되돌리기와 왼쪽 '히스토리' 메뉴는 무엇이 다른가요?**
**별개 기능**입니다. **되돌리기**는 지금 편집 중인 세션 안에서만 한
단계씩 되돌리는 것(최대 99단계, 세션을 닫으면 사라짐)이고,
**히스토리**는 세션을 닫고 **저장할 때마다 저장일시(날짜·시간)별
버전**이 쌓이는 보관함입니다 — 서버 저장과 연결되면 제공되며, 특정
시점 복귀는 현재 맵을 덮어쓰지 않고 **새 맵(제목_history_날짜)** 으로
열립니다.
