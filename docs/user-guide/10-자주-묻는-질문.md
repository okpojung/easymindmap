# 10. 자주 묻는 질문 (FAQ)

## AI

**Q. AI 생성이 "Gemini 호출 실패: 404 … no longer available"로 안 됩니다.**
구글이 그 모델을 없앤 것입니다. `AI 생성 → 설정 → Gemini 모델`에서
**"↻ 지금 키로 사용 가능한 모델 불러오기"** 를 눌러 현재 모델을 고르세요.

**Q. 제 ChatGPT/Claude 구독으로 API를 쓸 수 있나요?**
아니요. AI 사용료(API)는 구독과 **별개 요금**입니다. 각 회사 개발자
콘솔에서 API 키를 따로 발급받아야 합니다(키 발급 도움말 참고). Gemini만
결제 없이 쓸 수 있는 무료 사용량이 있습니다.

**Q. 노드를 고르고 질문을 적은 뒤 [선택 노드 자세히 확장]을 눌렀는데
엉뚱한 답이 나옵니다.**
2026-08-06 이전 버전입니다 — 그때는 확장이 **입력창 질문을 아예 쓰지
않고** 맵 내용(중심 주제 + 상위 경로 + 고른 노드)만 보고 답했습니다.
지금은 적어 둔 요청도 함께 보내고, 맵 문맥과 어긋나면 **그 요청을
따르라**고 지시합니다.
다만 맵과 **완전히 다른 주제**라면 확장이 아니라 `① AI에게 물어보기`
→ `② 새 맵 생성` 이 맞습니다 — 남의 노드 밑에 붙이면 자리가 이상합니다.

**Q. `① AI에게 물어보기`와 `선택 노드 자세히 확장`은 뭐가 다른가요?**
질문을 **꼭 적어야 하는 쪽**이 생성이고, **안 적어도 되는 쪽**이
확장입니다. 확장은 **맵의 내용 자체를 질문으로** 쓰기 때문입니다
(중심 주제 + `@소스` + 상위 경로 + 고른 노드). 결과도 생성은 새 맵/노드
중 고르지만, 확장은 **항상 고른 노드의 하위**로 들어갑니다.
→ [07. AI로 맵 생성](07-AI-생성.md) "먼저 — 버튼이 두 개입니다"

**Q. API 키를 등록했더니 AI 화면이 통째로 바뀌었습니다.**
키가 없을 때는 **웹 AI 모드**, 키가 생기면 **API 키 모드**가 기본으로
열립니다 — 두 화면은 구성이 다릅니다. 패널 위
`🌐 웹 AI (키 불필요)` 를 누르면 돌아가고, 선택은 저장됩니다.

**Q. AI가 만든 새 맵을 Ctrl+Z로 되돌릴 수 있나요?**
**없습니다.** 새 맵은 새 문서로 열리므로 되돌리기가 이전 맵으로 넘어가지
않습니다(넘어가면 정체불명의 맵이 섞입니다). 지금 맵에 저장하지 않은
편집이 있으면 **먼저 ☁ 저장**하세요 — 확인 창도 그렇게 안내합니다.
반면 **`선택 노드에 삽입`·`자세히 확장`은 지금 맵을 고치는 것**이라
Ctrl+Z로 되돌아갑니다.

**Q. AI 답변이 웹 채팅보다 짧습니다.**
설정에서 더 큰 모델을 고르세요(예: OpenAI `gpt-4.1`) — 소형(mini)
모델을 고른 상태는 아닌지 확인하세요. 기본 프롬프트가
"웹 채팅처럼 상세하게"로 되어 있는지도 확인하세요.

## 내보내기 / 뷰어

**Q. 내보낸 HTML을 열고 "모두 접기"를 했더니 화면이 비어요.**
예전에 내보낸 파일의 문제로, 최신 버전에서 고쳐졌습니다. 앱을 최신으로
갱신하고 **맵을 다시 내보내기** 하면 새 파일부터 정상 동작합니다 (이미
받아둔 옛 파일은 계속 깨져 있습니다).

**Q. 사진이 있는 맵을 MD로 내보냈더니 ZIP으로 받아져요.**
정상입니다. 사진·첨부는 `files/` 폴더에 담아 ZIP으로 묶습니다. 다시
불러올 때 ZIP 그대로 넣으면 사진까지 복원됩니다.

## 붙여넣기 / 콘텐츠 보존

**Q. 붙여넣은 뉴스 기사가 나중에 삭제되면 내 맵의 사진도 사라지나요?**
대부분 **아닙니다**. EasyMindMap은 붙여넣는 순간 **글은 텍스트로,
사진은 다운로드해 맵 안에 내장**하므로 원본 기사가 삭제되거나
오프라인이어도 그대로 남습니다. 노드에 붙여넣든 노트에 붙여넣든
같습니다. 단, 일부 사이트(브라우저 보안 정책상 다운로드가 막힌 경우)나
아주 큰 이미지(2.5MB 초과)는 사진이 **링크로 남아** 원본이 사라지면 안
보일 수 있습니다. (자세히: `docs/04-extensions/content-permanence.md`)

**Q. 내보낸 HTML/ZIP 파일도 오프라인에서 사진이 보이나요?**
내장된 사진은 파일 안에 들어가므로 **오프라인·다른 컴퓨터에서도** 보입니다.
링크로 남은 사진만 온라인일 때 보입니다.

## 저장

**Q. 내가 쓴 내용은 언제 저장되나요?**
두 군데에 나뉘어 저장됩니다.

| | 언제 |
| --- | --- |
| **이 브라우저(임시 보관)** | 노드를 추가·삭제하면 **즉시**, 글자를 치면 1초 뒤, 다른 탭으로 옮기거나 창을 닫으면 **즉시** |
| **서버** | **5분마다**(맵 설정에서 3·5·10분 중 선택) · 고친 곳이 **50개** 쌓였을 때 · **다른 탭으로 옮기거나 창을 닫을 때** · `☁ 저장`·`맵 닫기`를 눌렀을 때 |

**Q. 그럼 갑자기 전원이 나가면 어떻게 되나요?**
**서버에는 마지막 자동저장(최대 5분 전)까지만 반영돼 있습니다.** 그
사이 편집은 이 브라우저에 보관돼 있어서, 다시 열면
**"저장되지 않은 맵이 있습니다 — 복구할까요?"** 가 뜹니다. [복구]를
누르면 화면에 되살아납니다. 그 뒤 `☁ 저장`을 눌러 서버에 올리세요.

> 다만 **글자를 치던 도중에** 전원이 나가면 마지막 몇 글자는 남지
> 않을 수 있습니다. 중요한 시점에는 `☁ 저장`을 눌러 주세요.

**Q. 툴바의 `미저장 편집 12개` 는 무슨 뜻인가요?**
아직 **서버에 올라가지 않은** 편집이 12개 있다는 뜻입니다. 위 시점이
되면 자동으로 올라갑니다. 지금 바로 올리고 싶으면 `☁ 저장`을 누르세요
(그때만 히스토리 버전도 함께 남습니다).

**Q. 다른 PC에서 같은 맵을 열면 어떻게 되나요?**
**원래 PC에서 편집 중이면 `🔒 읽기 전용`으로 열립니다** — 다른 PC에서
고칠 수 없으니 서로 덮어쓸 일이 없습니다. 원래 PC에서 `맵 닫기`나 창
닫기로 정상적으로 끝내면(그때 서버로 올라갑니다) 다른 PC에서 **최신
내용 그대로** 편집할 수 있습니다.

**Q. 다른 PC에서 열었더니 조금 전에 한 작업이 없습니다.**
원래 PC가 **비정상으로 끝났을 때**만 생깁니다 — 크래시·전원 차단·
노트북 뚜껑 덮기·네트워크 끊김. 이 경우 편집권이 1분 뒤 풀리고, 다른
PC는 **마지막 자동저장(최대 5분 전)** 상태로 열립니다.

원래 PC를 다시 열면 **"저장되지 않은 맵이 있습니다 — 복구할까요?"** 가
뜨니 거기서 되살리세요. 그 사이 다른 PC에서 저장한 것이 있으면 두 갈래가
되므로, 복구본은 `☁ 저장` 시 **새 이름의 새 맵**으로 저장됩니다 —
다른 PC가 저장한 내용을 덮어쓰지 않습니다.

**Q. `브라우저 임시 보관에 실패했습니다` 가 떴어요.**
저장 공간이 부족해 임시 보관이 동작하지 않는 상태입니다 — **지금
편집은 이 브라우저에도 남지 않습니다.** `☁ 저장`을 눌러 서버에 올려
주세요.

**Q. `이 브라우저에서는 임시 보관을 쓸 수 없습니다` 가 떴어요.**
사생활 보호(시크릿) 모드이거나 저장소가 막혀 있습니다. 크래시 대비
보관이 동작하지 않으니 `☁ 저장`을 자주 눌러 주세요.

**Q. 노드를 접었다 폈다 한 것도 저장되나요?**
접고 편 상태는 **편집으로 세지 않습니다** — 접기만 해서는 저장도
되돌리기도 일어나지 않습니다. 다만 다른 편집이 저장될 때 함께 올라가서,
맵을 다시 열면 접어 둔 대로 보입니다.

## 화면 / 조작

**Q. 맵 전체 맞추기를 했더니 너무 작게(6%) 보입니다.**
노드가 아주 많은 맵입니다. 오른쪽 위 **"모두 접기"** 로 2레벨만 남기면
구조를 한눈에 볼 수 있습니다.

**Q. 실수로 맵을 지웠어요 / 새 맵으로 바뀌었어요.**
`Ctrl + Z`(되돌리기)로 복구됩니다. 되돌리기·다시 실행 버튼 사이
숫자(0/-1/-2…)가 몇 단계 되돌렸는지 보여 줍니다 (세션 안 최대 99단계).

**Q. `-5`까지 되돌렸는데, 이 상태를 최신으로 굳히고 싶어요.**
그 **숫자(`-5`)를 클릭**하면 지금 화면이 최신(0)이 되고 다시 실행할
5단계는 버려집니다. (아무 편집이나 한 번 해도 같은 결과가 됩니다.)

**Q. 저장했던 맵을 다시 열었더니 '중심 주제'만 남고 비어 있어요.**
이전 버전에서 맵을 전환하는 순간 자동저장이 빈 문서를 이전 맵에 쓸 수
있던 문제로, 2026-08-04 수정됐습니다. 이미 비어 버린 맵도 **명시
저장(`☁ 저장`·`맵 닫기`) 시점의 버전은 히스토리에 남아** 있을 가능성이
높습니다 — 그 맵을 연 상태에서 왼쪽 **히스토리**를 열고, 내용이 있는
버전(노드 수 확인)의 **`새 탭으로`** 를 눌러 복구하세요.

**Q. 되돌리기와 왼쪽 '히스토리' 메뉴는 무엇이 다른가요?**
**별개 기능**입니다. **되돌리기**는 지금 편집 중인 세션 안에서만 한
단계씩 되돌리는 것(최대 99단계, 세션을 닫으면 사라짐)이고,
**히스토리**는 `☁ 저장`·`맵 닫기` 때마다 저장일시별 버전이 쌓이는
보관함입니다. 각 줄의 **`새 탭으로`** 를 누르면 그 시점이
`제목_history_날짜_시각` 새 맵으로 만들어져 **브라우저 새 탭**에서
열립니다(현재 맵은 그대로).

**Q. `🔒 읽기 전용 — 다른 세션에서 편집 중` 배너가 떴어요.**
같은 맵을 다른 브라우저/탭이 편집 중입니다. 여기서 고친 내용은 그
맵에 저장되지 않습니다 — 남기려면 **⧉ 다른 이름으로 저장**으로 사본을
만드세요. 원래 세션을 닫으면 잠시 뒤(최대 1분) 편집권이 넘어옵니다.

**Q. 편집 중에 `편집권을 잃었습니다` 라고 나왔어요.**
다른 창이 같은 맵을 가져갔습니다. **지금까지 고친 내용은 이 브라우저에
보관됩니다** — 배지가 `저장 안 됨` 으로 바뀌고, `☁ 저장`을 누르면
**새 이름의 새 맵**으로 저장됩니다. 원래 맵을 덮어쓰지 않습니다.

**Q. 저장 버튼을 눌렀더니 가입하라고 나와요.**
Guest 체험 중에는 서버 저장이 막혀 있습니다 — 내보내기(MD·HTML)로
파일을 보관하거나 가입 후 저장하세요.
