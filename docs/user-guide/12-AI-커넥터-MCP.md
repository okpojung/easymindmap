# 12. AI 커넥터(MCP) — Claude 대화에서 바로 맵 만들기·읽기·덧붙이기

Claude 와 나눈 대화를 **복사·붙여넣기 없이** EasyMindMap 맵으로 저장하고,
문서함에 있는 맵을 Claude 가 **직접 읽어** 답하고, 그 답을 **맵의 원하는
노드 아래에 바로 붙이는** 기능입니다. 앱이 MCP(Model Context Protocol)
서버가 되어 Claude 가 도구처럼 부릅니다.

> **07-AI-생성(웹 AI·API 키)과 무엇이 다른가**
>
> | | 07 웹 AI (클립보드) | 07 API 키 | **12 AI 커넥터(MCP)** |
> |---|---|---|---|
> | 어디서 대화하나 | AI 웹 사이트 | 앱 안 | **claude.ai 채팅창** · **Claude Code** (PC·VS Code·웹 세션) |
> | 답을 맵으로 | 답 복사 → 앱에 붙여넣기 | 버튼 한 번 | **대화에서 "맵으로 저장해 줘"** |
> | 기존 맵을 AI 가 읽나 | ✗ (내가 붙여넣어야) | 선택 노드 주변만 | **✅ 문서함의 맵을 이름으로 읽는다** |
> | 답을 노드 아래에 | 내가 노드 골라 삽입 | 선택 노드 아래 | **✅ "'X > Y' 아래에 붙여 줘"** · 열어 둔 맵의 선택 노드에도 |
> | 필요한 것 | 없음 | AI 회사 API 키(과금) | **Claude 구독** (claude.ai 채팅창은 로그인만 · Claude Code 는 앱에서 발급한 토큰) |

## 1단계 — 앱에서 토큰 발급 (한 번)

> **2-C(claude.ai 채팅창)로만 쓰실 거면 이 단계는 건너뛰세요.** 토큰 대신
> 로그인으로 연결합니다. 2-A·2-B 에는 토큰이 필요합니다.

토큰은 "이 Claude 가 **내 계정**으로 맵을 만들어도 된다"는 열쇠입니다.

1. **로그인**합니다(Guest 는 안 됩니다 — 서버 저장이 있어야 합니다).
2. 상단 **오른쪽 끝 아바타** ▸ **🔌 AI 커넥터(MCP)**.
3. **토큰 이름**을 적습니다(예: `집 노트북 Claude`, `Claude 웹`). 어디서
   쓰는 토큰인지 나중에 알아보는 이름이면 됩니다. ▸ **[발급]**.
4. 화면에 **`emm_` 로 시작하는 원문**이 한 번 나타납니다.
   **[복사]** 를 눌러 지금 복사해 두세요.

   > **이 값은 다시 볼 수 없습니다.** 서버에도 남지 않습니다(암호화된
   > 지문만 저장). 잃어버리면 **[폐기]** 하고 새로 발급하면 됩니다.
5. 같은 화면 아래에 발급한 토큰 목록이 있습니다. 쓰지 않는 토큰은
   **[폐기] ▸ [정말 폐기]** 로 끄세요. 폐기는 즉시이고 되돌릴 수 없습니다.
6. 폐기된 토큰은 줄이 흐려진 채 남습니다(언제 껐는지 보려고). 치우려면
   그 줄의 **[삭제] ▸ [정말 삭제]** 를 누르세요. 살아 있는 토큰은 먼저
   폐기해야 지울 수 있습니다.

## 2-A. PC 의 Claude Code 에 연결

터미널(PowerShell·명령 프롬프트·macOS 터미널)에서 **한 줄**을 실행합니다.
`claude` 대화 **안이 아니라 밖**에서 실행합니다.

```bash
claude mcp add --transport http easymindmap https://api-dev.mindmap.ai.kr/v1/mcp --header "Authorization: Bearer emm_여기에_원문" --scope user
```

- `emm_여기에_원문` 자리에 1단계에서 복사한 값을 **통째로** 넣습니다.
  `Bearer` 와 토큰 사이 **띄어쓰기 한 칸**입니다.
- **한 줄로** 넣으세요. PowerShell 에서 `\` 로 줄을 나누면 명령이 깨집니다.
- `--scope user` 를 붙이면 **어느 폴더에서 `claude` 를 열어도** 보입니다.
  빼면 지금 폴더에서만 보입니다.

**붙었는지 확인**

```bash
claude mcp list
```

`easymindmap: … - ✓ Connected` 가 나오면 됩니다(Windows 옛 콘솔은
`√ Connected` 로 보입니다). 이제 `claude` 를 열고 대화하면 됩니다.
대화 안에서 `/mcp` 를 치면 같은 것을 보고, 서버를 고르면 도구 5개가
보입니다.

**토큰을 바꿀 때** — 지우고 다시 등록합니다.

```bash
claude mcp remove easymindmap --scope user
claude mcp add --transport http easymindmap https://api-dev.mindmap.ai.kr/v1/mcp --header "Authorization: Bearer emm_새_원문" --scope user
```

> **토큰이 PC 의 `~/.claude.json` 에 그대로 저장됩니다.** 공용 PC 라면
> 쓰고 나서 `claude mcp remove easymindmap --scope user` 로 지우고 앱에서
> **[폐기]** 하세요.

## 2-B. Claude Code 웹(claude.ai/code)에 연결

웹 세션은 PC 의 설정을 가져오지 않습니다. 대신 **EasyMindMap 저장소 안의
설정 파일(`.mcp.json`)** 을 읽고, 토큰은 **클라우드 환경의 환경 변수**에서
가져옵니다. 그래서 환경을 한 번 만들어 두면 됩니다.

1. [claude.ai/code](https://claude.ai/code) 첫 화면에서 **입력창 바로 위
   줄의 구름 아이콘**(환경 이름, 처음엔 `Default`)을 누릅니다.
2. **[클라우드 환경 추가]** (이미 만든 환경을 고치려면 환경 위에 마우스를
   올려 오른쪽 **톱니** 아이콘).
3. 대화상자를 이렇게 채웁니다.

   | 칸 | 넣을 것 |
   |---|---|
   | **이름** | `easymindmap-mcp` (아무 이름) |
   | **네트워크 액세스** | `신뢰됨` 을 **`사용자 지정`** 으로 바꾸고, 새로 나타나는 **허용 도메인**에 `api-dev.mindmap.ai.kr` 한 줄 |
   | **환경 변수** | 예시 글자를 지우고 `EMM_MCP_TOKEN=emm_여기에_원문` 한 줄 (따옴표·공백 없이) |
   | **설정 스크립트** | 비워 둡니다 |

   ▸ **[환경 추가]**.

   <!-- TODO(스크린샷): assets/mcp-cloud-env.png — 클라우드 환경 추가 대화상자 -->

4. 첫 화면으로 돌아와 아래 줄이 **☁ easymindmap-mcp · 저장소 easymindmap ·
   브랜치 main** 인지 확인합니다. 저장소는 **`okpojung/easymindmap`** 이어야
   합니다 — 설정 파일이 그 저장소 안에 있습니다.
5. 입력창에 **첫 메시지를 씁니다**(예: `내 EasyMindMap 맵 목록 보여줘`).
   Enter 를 치면 세션이 만들어지고(30초~1분) Claude 가 자동으로 연결해
   맵 목록을 보여 줍니다.

> `/mcp` 는 **세션 안에서** 칩니다. 첫 화면(세션 밖)에서 치면 claude.ai
> 의 커넥터 디렉터리가 열리는데, 그 스토어에 EasyMindMap 은 없습니다.

**토큰을 바꿀 때** — 환경의 환경 변수만 고치고 **새 세션**을 엽니다.
이미 돌고 있던 세션은 바뀐 값을 읽지 않습니다.

## 2-C. claude.ai 채팅창에 연결 (가장 쉽습니다)

**토큰이 필요 없습니다.** 주소 하나만 넣으면 EasyMindMap 로그인 화면이 뜨고,
로그인하면 연결됩니다.

1. claude.ai 오른쪽 위 **프로필 ▸ 설정(⚙)** → 왼쪽에서 **커넥터**
2. **[커스텀 커넥터 추가]**
3. 두 칸만 채웁니다.

   | 칸 | 넣을 값 |
   |---|---|
   | 이름 | 아무거나 (예: `emm`) |
   | 주소 | `https://api-dev.mindmap.ai.kr/v1/mcp` |

4. **나머지는 그대로 두세요.** `인증`·`OAuth 클라이언트` 는 claude.ai 가
   자동으로 고릅니다(`감지됨` 이라고 표시됩니다). **추가 요청 헤더는
   비워 둡니다.**
5. **[추가]** → EasyMindMap **로그인 화면**이 뜹니다 → 로그인
6. **"Claude 을(를) 연결할까요?"** 화면에서 무엇을 허락하는지 확인하고
   **[허용]**
7. 커넥터가 **연결됨** 으로 바뀌고, 도구 **5개**가 잡히면 끝입니다.

   > EasyMindMap 문서함의 맵 목록 · 맵 한 개를 마크다운으로 읽기 ·
   > 지금 열어 둔 맵과 선택한 노드 · 새 마인드맵 만들기 ·
   > 기존 맵의 노드 아래에 가지 붙이기

### 잘 안 될 때

| 증상 | 이렇게 하세요 |
|---|---|
| **"연결 문제 / 다시 연결하세요"** 가 계속 뜬다 | 커넥터를 **지우고 새로 추가**하세요. [다시 연결] 은 예전 설정을 그대로 쓸 수 있습니다 |
| 로그인 창이 안 뜬다 | 팝업 차단일 수 있습니다 — 주소창 오른쪽의 차단 아이콘을 확인하세요 |
| 동의 화면에서 **"이 연결 요청을 찾을 수 없습니다"** | 연결을 시작하고 **10분**이 지나면 만료됩니다. 처음부터 다시 하세요 |

### 연결을 끊으려면

claude.ai 의 같은 커넥터 화면에서 **[연결 해제]** 를 누릅니다.

> **앱(EasyMindMap) 쪽에는 이 연결을 끊는 화면이 없습니다.** 앱의
> [🔌 AI 커넥터(MCP)] 화면은 **2-A·2-B 가 쓰는 토큰(`emm_…`)** 만
> 다룹니다 — 2-C 로 연결한 것은 거기 목록에 나오지 않고, 거기서 [폐기]
> 해도 2-C 연결은 끊기지 않습니다.

## 3단계 — 대화에서 이렇게 말합니다

명령어를 외울 필요는 없습니다. Claude 가 말을 알아듣고 도구를 고릅니다.
아래는 **잘 통하는 말** 입니다.

| 하고 싶은 것 | 이렇게 말한다 | 결과 |
|---|---|---|
| 대화 내용을 새 맵으로 | `지금까지 정리한 내용을 EasyMindMap 맵으로 저장해 줘` / 짧게 `emm 으로 작성해 줘` | 문서함 홈에 새 맵이 생깁니다(문서함을 열어 보면 있습니다). **"emm" 은 EasyMindMap 의 준말**로 알아듣습니다 |
| 맵 모양 고르기 | `…PT 템플릿으로 emm 으로 작성해 줘` / `…진행트리-트리맵 템플릿으로` | 아래 **템플릿 ID 표**의 ID·한글명·영문명 어느 것이나 됩니다 |
| 내 맵 목록 | `내 EasyMindMap 맵 목록 보여줘` / `'기획' 폴더의 맵만` / `'회의' 들어간 맵 찾아 줘` | 이름·폴더·수정 시각·노드 수. 공유받은 맵도 "공유받음" 으로 |
| 맵 읽기 | `'주간 회의 정리' 맵 읽어서 요약해 줘` | Claude 가 맵을 아웃라인(마크다운)으로 읽고 답합니다 |
| 답을 노드 아래에 | `그 답을 '다음 회의 > 안건' 아래에 붙여 줘` | 그 노드 **맨 뒤**에 가지로. 아웃라인에 보이는 이름 그대로 가리키면 됩니다(`### 안건` 처럼 `#` 이 붙어 있어도 됨) |
| 최상위 가지로 | `'회고' 맵에 새 가지로 붙여 줘` (부모를 말하지 않음) | 중심 주제 바로 아래 |
| **지금 보고 있는 맵의 고른 노드에** | 앱에서 노드를 클릭해 두고 `지금 열려 있는 맵의 선택한 노드 아래에 '검토 요청', '승인 대기' 붙여 줘` | 앱 화면에 몇 초 안에 나타납니다 |
| 코드는 노트로 | `코드는 노트코드로 첨부해 줘` | 코드블록이 자식 노드가 아니라 **그 노드의 코드 노트**로 |
| 긴 글은 노트로 | `300자 이상 긴 문장은 노트 문단으로 작성해 줘` (글자 수 안 말하면 300) | 긴 문단이 **문단 노트**로. 짧은 문단은 그대로 노드 |
| **완료 체크** (2026-09-09) | 할 일 맵을 열어 두고 `현재 맵에서 완료된 항목은 완료 체크에 체크해 줘` / `'1단계 범위' 끝났으니 체크해 줘` / `…체크 해제해 줘` | 그 노드의 **체크박스**(`- [ ] 완료` 줄, 체크리스트 노트)가 `[x]` 로. 글은 한 글자도 안 바뀝니다. 무엇이 끝났는지 대화에 없으면 Claude 가 체크박스 있는 노드를 보여 주고 **되묻습니다**(짐작해서 체크하지 않음). 이름이 둘 이상에 걸리면 `'3단계 > 1단계 범위'` 처럼 경로로 |
| 말 안 하면 | — | 표·코드·문단 **전부 노드 내용**입니다(기본) |

**템플릿·레이아웃 ID** — 한글명을 매번 적기 번거로우면 **두 글자 ID** 로
말하세요(대소문자 상관없음). MD 파일의 ```` ```emm ```` 선언(`template: PT`)에도
같은 ID 를 씁니다. MD 파일은 이렇게 씁니다 — **`# 제목` 이 먼저**, 그 다음
선언 블록을 **``` 로 닫고**, 그 아래 가지:

````markdown
# 시험

```emm
template: PT
```

## 가지 하나
### 손자 A
## 가지 둘
````

> 닫는 ``` 을 잊으면 예전에는 뒤 내용이 전부 코드로 들어가 "맵으로 만들
> 구조를 찾지 못했습니다" 가 뜨거나 루트 하나만 생겼습니다. 2026-09-07
> 부터는 첫 `#` 줄 앞에서 닫힌 것으로 보고 정상으로 불러옵니다. 그래도
> 닫아 주는 것이 바른 형식입니다.

| ID | 한글명 (영문명) | 모양 |
|---|---|---|
| **TP** | 트리-진행트리맵 (tree-progtree) — **기본** | 1레벨 트리 → 2레벨 진행트리 → 3레벨 트리 → 4레벨+ 진행트리 |
| **PT** | 진행트리-트리맵 (progtree-tree) | 1레벨 진행트리 → 2레벨+ 트리 |
| **RB** | 방사형 양쪽 (radial-bidirectional) | 중심에서 양쪽으로 |
| **RR** / **RL** | 방사형 오른쪽 / 왼쪽 (radial-right / radial-left) | 한쪽으로만 |
| **TR** / **TL** / **TD** / **TU** | 트리 오른쪽 / 왼쪽 / 아래 / 위 (tree-right / -left / -down / -up) | 트리 |
| **PR** / **PL** | 진행트리 오른쪽 / 왼쪽 (process-tree-right / -left) | 진행트리 |
| **HR** / **HL** | 계층형 오른쪽 / 왼쪽 (hierarchy-right / -left) | 조직도·WBS |
| **KB** | 칸반 (kanban) | 칸반 보드 |
| **TM** / **TC** | 시간배치 / 시간배치 가운데 (timeline / timeline-center) | 타임라인 |
| **FF** | 자유배치 (freeform) | 자유 |

외우는 법: 첫 글자가 종류(T 트리 · P 진행트리 · R 방사형 · H 계층형 · K 칸반),
둘째 글자가 방향(R 오른쪽 · L 왼쪽 · D 아래 · U 위). `TP`·`PT` 는 층의 첫
글자를 순서대로 이어 붙인 것입니다(트리→진행트리, 진행트리→트리).

**예 — 설치 절차를 만들고, 오류를 그 절차 노드 아래에 정리하기**

앱에 맵을 열어 둔 채 Claude 대화(2-A·2-B·2-C 어디서나)에서:

1. `wordpress 설치 절차를 PT 템플릿으로 emm 으로 작성해 줘` → 문서함에
   "워드프레스 설치 절차" 맵이 생깁니다(1레벨 진행트리). 앱에서 엽니다.
2. 3단계 명령을 실행했더니 오류가 났습니다. 세션에 오류 원문을 붙이고:
   `이 오류의 원인과 해결 방법을 emm 맵의 3단계 절차 노드 아래에 추가해 줘.
   오류 원문은 코드블록으로.` → 3단계 노드 아래에 **오류 → 원인 → 해결**
   가지가 붙고, 열어 둔 앱 화면에 몇 초 안에 나타납니다.
3. 오류 **화면 캡처**도 넣고 싶으면 **파일로 저장한 뒤 경로를 말합니다**:
   `오류 화면은 C:\Users\me\Desktop\err.png 에 있다. 이 사진도 함께 넣어 줘`
   → 그 노드 아래에 사진 노드가 생깁니다(대체 텍스트가 이름, 표시 폭 640 까지).
   Claude 가 파일을 base64 로 읽어 보내므로 PC 의 Claude Code 에서 됩니다.

> 대화창에 **붙여 넣은** 이미지는 Claude 가 보기만 하고 파일 바이트를 꺼낼
> 수 없어 맵에 넣지 못합니다. 이 경우 Claude 가 화면에 보이는 내용을 글로
> 옮겨 적습니다. 사진 자체를 넣으려면 3번처럼 파일 경로를 주세요.

**앱에서 보이는 것**

- 맵을 **열어 둔 채**여도 Claude 가 붙일 수 있습니다. 화면은 5초 안에
  갱신되고 "AI 대화에서 이 맵을 갱신했습니다" 토스트가 뜹니다. 확대·이동·
  선택은 그대로입니다.
- **편집하던 중**이면 AI 가 붙인 가지가 내 편집 위에 **합쳐집니다**
  ("붙인 가지 N개를 화면에 합쳤습니다"). 그 뒤 ☁ 저장하면 둘 다 서버에
  남습니다.
- 붙일 때마다 **버전 기록**이 남습니다(Claude 가 "버전 N" 이라고
  알려 줍니다). 마음에 안 들면 **히스토리에서 그 이전 버전으로
  되돌리면** 됩니다(11-버전기록). 지우는 도구는 일부러 두지 않았습니다.

## 제약사항 — 알고 쓰면 당황하지 않습니다

### 무엇을 못 하나 (도구의 범위)

- **덧붙이기와 체크뿐입니다.** 있는 노드의 글을 **고치거나, 지우거나, 옮기지
  못합니다.** "3번 노드 이름 바꿔 줘" 는 안 됩니다 — 앱에서 직접 고치세요.
  예외는 **체크박스**(`- [ ] 완료` 줄 · 체크리스트 노트)의 체크/해제
  하나입니다(2026-09-09) — 그것도 `[ ]`↔`[x]` 한 글자만 바뀌고 버전이
  남습니다.
- 붙는 자리는 **항상 부모의 맨 뒤**입니다. "두 번째 자리에" 같은 위치
  지정은 없습니다.
- 새 맵은 **문서함 홈**에 생깁니다. 폴더로 옮기는 것은 앱에서 합니다.
- 노드 깊이는 **50단계**까지입니다.
- 맵 삭제·이름 변경·공유·퍼블리싱은 도구에 없습니다. 전부 앱에서 합니다.
- **사진**은 파일 경로로 준 것만 넣을 수 있습니다(PNG·JPEG·GIF·WebP, 한 장
  2.5MB 까지). 대화창에 붙여 넣은 이미지는 넣지 못합니다. 웹 세션(2-B)은
  PC 파일을 못 읽으니 사진 넣기는 **PC 의 Claude Code** 에서 하세요.

### 붙일 자리를 이름으로 찾는 규칙

- 정확히 같은 이름 → 없으면 그 말이 **들어간** 이름 → **둘 이상이면
  붙이지 않고 후보를 보여 주며 되묻습니다**. 그때는 `'상위 > 하위'` 처럼
  경로로 다시 말하면 됩니다.
- 붙이는 내용이 **줄글만**이면 노드가 되지 않아 거절합니다. 목록(`- 항목`)
  이나 소제목(`## 이름`) 형태여야 합니다. 보통 Claude 가 알아서 만듭니다.

### 언제 거절되나

| 상황 | 무슨 일이 | 어떻게 |
|---|---|---|
| **공개(퍼블리싱) 중인 맵** | "공개 중" 이라며 거절 | 앱에서 **비공개(보관)** 로 바꾼 뒤 다시 |
| **다른 사람이 그 맵을 편집 중** (공유 편집자) | "편집 중" 거절 | 그 사람이 닫거나 1분쯤 조용해지면 됩니다. **내가** 열어 둔 것은 괜찮습니다 |
| 공유받은 맵인데 **읽기 권한만** | 거절 | 읽기(`get_map`)는 됩니다. 붙이려면 편집 권한이 필요합니다 |
| **협업맵을 앱에 열어 둔 동안** | "협업 방이 열려 있어…" 거절 (2026-09-09부터) | 그 맵을 **앱에서 닫고 1분쯤 뒤에** 다시 말하세요. 읽기(`get_map`)는 그대로 됩니다 |
| Guest 계정 | 2-A·2-B 는 토큰 발급 자체가 안 되고, 2-C 는 로그인이 안 됩니다 | 가입·로그인 후 |

### 덮어쓰기 방지 — 드물게 보는 안내

편집 중인 탭에서 ☁ 저장할 때 "AI 대화가 이 맵을 먼저 바꿔서…" 안내가
뜨면, **내 편집분은 초안으로 보관**되고 맵을 다시 열면 **초안 복구 배너**
가 나옵니다. AI 가 **덧붙이기만** 하는 지금은 거의 만나지 않지만, 만나면
당황하지 말고 다시 열어 복구하세요.

### "지금 열려 있는 맵 · 선택한 노드"의 조건

- **앱 탭이 열려 있어야** 합니다. 서버는 앱이 5초마다 보내는 신호로
  "지금 이 맵·이 노드" 를 압니다. 탭을 닫으면 **60초 뒤 잊습니다** —
  그러면 Claude 가 "열린 맵이 없다" 고 합니다.
- 노드를 고른 뒤 **0.5초** 지나면 서버가 압니다. 고르자마자 말해도
  대개 괜찮습니다.

#### 다른 브라우저·다른 PC 에서 열어도 되나요 — **네, 됩니다**

Claude 를 쓰는 브라우저와 EasyMindMap 을 여는 브라우저가 **달라도 됩니다.**
**다른 PC·태블릿이어도 됩니다.** 조건은 하나 — **같은 계정으로 로그인**해야
합니다. 서버는 "어느 브라우저" 가 아니라 **"어느 회원"** 으로 기억합니다.

| 이렇게 써도 되나 | |
|---|---|
| Claude 는 크롬, EasyMindMap 은 웨일 | ✅ |
| Claude 는 사무실 PC, EasyMindMap 은 집 PC·태블릿 | ✅ |
| EasyMindMap 을 **다른 계정**으로 로그인 | ❌ 서버가 이어 주지 못합니다 |

#### 같은 맵을 여러 곳에서 열면 — **헷갈리지 않습니다**

같은 맵을 두 번째로 열면 그 창은 **읽기 전용**이 됩니다(편집 잠금). 그리고
**읽기 전용 창은 "지금 보는 자리" 를 아예 보내지 않습니다.**

> 그래서 읽기 전용 창에서 노드를 클릭해도 Claude 는 그것을 "선택한 노드" 로
> 보지 않습니다. **편집할 수 있는 창의 선택만** 따릅니다.

먼저 연 창을 닫으면 60초 뒤 잠금이 풀립니다. 그때 두 번째 창을
**새로고침**하면 그쪽이 편집권을 가져가고, 그다음부터는 그 창의 선택을
따릅니다. (자동으로 넘어가지는 않습니다 — 새로고침이 필요합니다.)

#### 헷갈릴 수 있는 경우 하나 — **서로 다른 맵**

여러 곳에서 **각각 다른 맵**을 편집 중이면(둘 다 편집권), **가장 최근에
신호를 보낸 쪽**이 "지금 열린 맵" 이 됩니다. 5초마다 보내므로 둘이 번갈아
이길 수 있습니다.

**의심스러우면 붙이기 전에 물어보세요.**

> "지금 열려 있는 맵이 뭐야?"

맵 이름 · 선택한 노드 · **몇 초 전에 신호가 왔는지**까지 알려 줍니다.

#### 알아 둘 것 하나

이 값은 서버 메모리에만 둡니다(몇 초마다 바뀌는 값이라 저장하지 않습니다).
그래서 **서버가 재시작된 직후 잠깐** 은 "열린 맵이 없다" 가 나올 수 있습니다.
앱이 5초 안에 다시 보내므로 잠시 뒤 다시 말하면 됩니다.

### 맵 읽기(get_map)의 한계

- **12만 자**에서 잘립니다. 잘리면 Claude 가 그 사실을 말합니다. 아주 큰
  맵은 앱의 [내보내기 ▸ Markdown] 으로 파일을 주는 편이 낫습니다.
- **사진은 읽지 않습니다.** 자리(`files/img-1.png`)만 표시되고 "사진 N장"
  으로 셉니다.
- 색·모양·좌표 같은 **스타일은 읽지 않습니다.** 글 구조(아웃라인)만
  읽습니다.
- 읽기는 편집 잠금을 잡지 않습니다. 누가 편집 중이어도 읽을 수 있습니다.
- 큰 맵을 읽으면 그만큼 **대화 토큰**을 씁니다. 필요한 맵만 읽게 하세요.

### 토큰과 보안 — **2-A·2-B 를 쓸 때만 해당합니다**

> 2-C(claude.ai 채팅창)에는 토큰이 없습니다. 대신 **로그인한 그 계정**으로
> 연결되고, 끊는 것은 claude.ai 의 **[연결 해제]** 입니다.

- 토큰 하나로 **내 계정의 모든 맵**을 읽고 붙일 수 있습니다. 비밀번호처럼
  다루세요.
- PC 에서는 `~/.claude.json` 에 **평문**으로 남습니다. 공용 PC 에서는
  쓰고 지우세요(2-A 끝).
- 웹 환경의 환경 변수는 "그 환경을 쓰는 사람이 읽을 수 있다" 고 화면이
  경고합니다. **개인 환경**이면 본인뿐이니 괜찮고, **조직 공유 환경에는
  넣지 마세요.**
- 이상하면 앱에서 **[폐기]** — 그 순간부터 그 토큰은 401 을 받습니다.
- 살아 있는 토큰 10개 상한. 마지막 사용 시각을 보고 안 쓰는 것을 정리하세요.

### 서버·환경

- 클라우드 서버(`api-dev.mindmap.ai.kr`)에 로그인한 계정만 됩니다.
  **내 컴퓨터에서 돌리는 로컬 실행**(로컬-실행.md 의 `dev` 모드)은 MCP 를
  열지 않고 403 을 냅니다 — 로그인 없이 아무나 되는 모드라 일부러
  막았습니다. 토큰 화면에도 같은 안내가 뜹니다.
- 웹 세션은 **`okpojung/easymindmap` 저장소로 연 세션**에서만 됩니다.
  다른 저장소 세션에는 설정 파일이 없습니다.
- 웹 세션은 환경마다 따로입니다. 환경을 새로 만들면 도메인·환경 변수도
  다시 넣어야 합니다.
- **PC 에서 EasyMindMap 저장소 폴더 안**에서 `claude` 를 열면, 저장소의
  설정 파일이 PC 의 등록(2-A)을 **가립니다**. 그 폴더에서도 쓰려면 PC 에
  환경 변수 `EMM_MCP_TOKEN` 을 두거나(PowerShell:
  `[Environment]::SetEnvironmentVariable('EMM_MCP_TOKEN','emm_…','User')`
  뒤 터미널 새로 열기), 처음 뜨는 승인 물음에서 거절하면 됩니다. 저장소
  **밖** 폴더에서는 해당 없습니다.
- 도구가 새로 늘어난 뒤에는 열려 있던 세션이 옛 목록을 들고 있습니다.
  2-A·2-B 는 `/mcp` 에서 서버를 고르고 **reconnect** 하거나 새 세션을,
  2-C 는 claude.ai **설정 ▸ 커넥터**에서 그 커넥터를 한 번 열어 보거나
  **새 대화**를 시작하세요.

## 문제 해결

| 보이는 것 | 원인 | 조치 |
|---|---|---|
| `401` / "토큰이 유효하지 않거나 폐기되었습니다" | 토큰이 틀렸거나 폐기됨, 앞뒤 공백·줄바꿈 | 앱에서 새로 발급 → 2-A 는 remove 후 add, 2-B 는 환경 변수 고치고 **새 세션** |
| `403` "인증을 켠 배포에서만 동작합니다" | 로컬 실행(dev 모드) 서버 | 클라우드 주소(`api-dev.mindmap.ai.kr`)로 |
| `Dynamic Client Registration rejected … Cannot POST /register` | 헤더 없이 등록돼 OAuth 를 찾음 | `--header "Authorization: Bearer emm_…"` 를 넣어 다시 add |
| `Header 'Authorization' has invalid value` | `emm_…` 같은 **자리표시 글자를 그대로** 넣음 | 실제 토큰 원문으로 |
| `401` **"토큰 형식이 아닙니다 … 자리표시"** | `.mcp.json` 의 `${EMM_MCP_TOKEN}` 이 **환경 변수 없이 그대로** 전송됨 (그 글자가 서버까지 옵니다) | 환경 변수 `EMM_MCP_TOKEN` 을 실제 토큰(`emm_…`)으로 두고 **새 세션** |
| PowerShell 에서 명령이 조각남 | `\` 줄 나눔 | 한 줄로 |
| `Failed to connect` (웹 세션) | 환경의 허용 도메인에 `api-dev.mindmap.ai.kr` 이 없음 | 네트워크 액세스 `사용자 지정` + 도메인 추가 → 새 세션 |
| `/mcp` 를 쳤는데 커넥터 스토어가 열림 | **세션 밖**에서 침 | 첫 메시지를 보내 세션을 만든 뒤 세션 안에서 |
| 도구가 3개만 보임 | 옛 세션이 옛 목록을 기억 | `/mcp` ▸ reconnect 또는 새 세션 |
| "편집 중입니다" | 다른 사람이 그 맵을 열어 둠 | 닫힐 때까지(1분쯤 조용하면 자동 해제) |
| "공개 중인 맵" | 퍼블리싱 상태 | 앱에서 비공개로 |
| "'X' 가 여러 곳에 있습니다" + 후보 | 같은 이름 노드가 둘 이상 | `'상위 > 하위'` 경로로 다시 |
| "열린 맵이 없습니다" | 앱 탭이 닫혔거나 60초 지남 | 앱에서 맵을 열고 노드를 고른 뒤 다시 |
| 붙였다는데 화면에 안 보임 | 5초 갱신 전, 또는 다른 맵을 보고 있음 | 잠시 기다리거나 문서함에서 그 맵 열기 |
| **"협업 방이 열려 있어…"** | 협업맵을 앱에 열어 둠 | 그 맵을 닫고 **1분쯤** 뒤에 다시 |
| (2-C) **"연결 문제 / 다시 연결하세요"** | 커넥터가 옛 설정을 들고 있음 | 커넥터를 **지우고 새로 추가** — 위 **2-C ▸ 잘 안 될 때** |

> **파일을 열어 보면 적혀 있습니다** (2026-09-07) — 저장소의 `.mcp.json` 맨 위
> `"//"` 항목에 "토큰이 없으면 무슨 일이 생기나 · 확인하는 법 · 고치는 법" 을
> 적어 두었습니다. 붙기 전에 확인하려면 이 한 줄이 가장 빠릅니다:
>
> ```
> claude mcp list
> # └ [Warning] mcpServers.easymindmap: Missing environment variables: EMM_MCP_TOKEN
> ```
>
> 이 경고가 보이면 **서버가 아니라 환경 변수** 문제입니다.

> **"이 서버는 OAuth 커넥터가 설정되지 않았습니다" 가 떴다면** — 그것은
> 서버 이야기입니다. 토큰이 아니라 **그 배포에 OAuth 가 아직 안 켜진**
> 것이니, PAT(`emm_…`)으로 붙이거나 운영자에게 `GOTRUE_PUBLIC_URL` 을
> 물어보세요. (2026-09-06 이전에는 **자리표시를 넣었을 때도** 이 문장이
> 떠서 엉뚱한 곳을 보게 했습니다 — 지금은 토큰 형식을 짚어 줍니다.)
