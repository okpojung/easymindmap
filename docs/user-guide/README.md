## 한눈에 보기 (30초 요약)

1. **새 맵 만들기** → 왼쪽 `+ 새 맵` → `새 맵 만들기` →
   템플릿 선택(또는 `건너뛰기(기본 그대로)`)
2. **노드 추가** → 노드 선택 후 `Space`(자식) / `Shift+Space`(형제),
   또는 노드에 마우스를 올리면 나오는 `+` 버튼
3. **글자 편집** → 노드 **더블클릭**
4. **레이아웃 바꾸기** → 중심 주제 선택 → 속성 `레이아웃` 탭
5. **AI로 만들기** → 상단 `AI 생성` → 🌐 웹 AI(키 불필요)로 프롬프트
   복사·답변 붙여넣기, 또는 🔑 API 키 모드
6. **저장/공유** → 상단 `내보내기` → HTML(뷰어) 또는 MD 파일

> 가입 없이 체험하려면 로그인 화면의 **👤 Guest로 체험하기**
> (편집·내보내기·웹 AI 가능, 서버 저장·첨부는 가입 후).
