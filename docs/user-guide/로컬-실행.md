# 로컬에서 실행하기 (내 컴퓨터에서 테스트)

> 내 PC에서 EasyMindMap을 띄워 직접 써보는 방법. 편집 기능만 볼 수도 있고,
> **클라우드 저장**까지 포함한 전체를 띄울 수도 있다.

## 준비물

- **Node.js 20 이상** — 터미널에서 `node -v` (없으면 https://nodejs.org)
- **Docker Desktop** — *클라우드 저장까지* 볼 때만 필요(DB용).
  편집 기능만 볼 거면 없어도 된다. (https://www.docker.com)

## 0. 최신 코드 받기

```bash
cd easymindmap
git checkout main
git pull origin main
```

---

## 방법 A — 원터치 스크립트 (권장)

DB + 백엔드 + 프론트를 한 번에 띄운다. 스크립트가 시작할 때 **Docker 설치·
실행 여부를 먼저 확인**하고, 없으면 설치를 제안한다:

- **Docker 미설치** → 설치 여부를 물어본다(y/N).
  - Windows: `winget` 으로 Docker Desktop 설치 제안
  - Linux: Docker 공식 스크립트(`get.docker.com`, sudo) 제안
  - macOS: Homebrew 로 Docker Desktop 설치 제안
- **Docker 설치됐지만 미실행** → Docker Desktop 실행(또는 `systemctl start
  docker`) 안내 후 종료. Docker 를 켜고 다시 실행하면 된다.

- **macOS / Linux**
  ```bash
  ./dev.sh
  ```
  (처음 한 번만 `chmod +x dev.sh` 가 필요할 수 있다.)

- **Windows** — 명령 프롬프트(cmd)에서:
  ```cmd
  dev
  ```
  (`dev.cmd` 래퍼가 PowerShell 스크립트를 올바로 실행한다. PowerShell 창에서
  직접 하려면 `powershell -ExecutionPolicy Bypass -File dev.ps1`)

  > ⚠️ cmd 에서 `dev.ps1` 을 그냥 치면 “이 파일을 열 앱 선택” 팝업이 뜬다.
  > 이는 cmd 가 .ps1 을 직접 실행하지 못하기 때문 — 위처럼 `dev` 로 실행할 것.

→ 브라우저에서 **http://localhost:5173** 접속.
종료: macOS/Linux는 `Ctrl + C`, Windows는 열린 두 창을 닫는다.
DB 끄기: `docker compose -f apps/api/docker-compose.dev.yml down`

## 방법 B — 손으로 하나씩

### 편집 기능만 (백엔드·Docker 불필요)

```bash
cd apps/frontend
npm install
npm run dev            # → http://localhost:5173
```

☁ 클라우드 버튼은 백엔드가 없어 “서버에 연결할 수 없습니다”가 뜨는 게
정상이다. 그 외 편집·AI·내보내기 등은 모두 동작한다.

### 클라우드 저장까지 (터미널 3개)

```bash
# ① DB (Docker)
cd apps/api
docker compose -f docker-compose.dev.yml up -d

# ② 백엔드
cd apps/api
npm install
cp .env.example .env       # Windows: copy .env.example .env
npm run start:dev          # → http://localhost:3000/v1

# ③ 프론트 (새 터미널)
cd apps/frontend
npm install
npm run dev                # → http://localhost:5173
```

## 무엇을 눌러보나

- 우상단 **☁ 클라우드 ▼ → 저장** → “클라우드에 저장했습니다” 토스트
- 이후 노드를 편집하면 툴바 배지가 **저장 중… → 저장됨** (자동 저장)
- **☁ → 열기** → 저장한 맵 목록에서 **열기 / 이름변경(✏) / 삭제(🗑)**

## 문제 해결

| 증상 | 확인 |
|---|---|
| 클라우드 저장이 “서버에 연결할 수 없습니다” | 백엔드(②)가 켜져 있는지. `http://localhost:3000/v1/health` 가 `{"status":"ok"}` 인지 |
| DB 관련 오류 | Docker Desktop 이 실행 중인지, `docker compose ... up -d` 가 성공했는지 |
| 포트 충돌 | 5173 / 3000 / 5432 를 다른 프로그램이 쓰고 있는지 |
| 로그인/계정 | 현재는 **개발 모드(로그인 없는 단일 사용자)**. 계정 분리는 다음 단계(Supabase Auth) |

> 참고: 지금은 클라우드 링크가 **세션 한정**이라, 새로고침하면 기본 문서로
> 시작한다. 이어서 편집하려면 **☁ → 열기**로 저장했던 맵을 불러오면 된다.
