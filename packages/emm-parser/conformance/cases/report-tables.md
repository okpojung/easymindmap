## PART 1. 유사 사례 조사

### 1-1. 핵심 결론 (먼저 제시)

국내외 사내 도서관 12곳을 조사한 결과, **모든 사례가 "직원이 직접 신청해야" 도서가 구비되는 구조**였다. 신청 마찰을 없앤 **자동 추천-자동 구비** 구조라야 이용률이 구조적으로 오른다는 점이 본 제안의 차별성이다.

### 1-2. A사 — 자동 추천 모델 (절반의 성공)

| 항목 | 내용 |
|------|------|
| 도입 | 2024년 3월 |
| 핵심 | 사내 검색 로그 기반 도서 자동 추천 |
| 규모 | 임직원 1,200명 · 장서 8,400권 |
| 한계 | 추천 후 **신청 버튼**을 눌러야 구비 — 이용률 38%에 정체 |

**시사점:** 추천까지 자동화해도 신청 마찰이 한 단계 남으면 이용률이 절반 수준에 머문다.

### 1-3. B사 — 완전 자동 구비 모델

| 항목 | 내용 |
|------|------|
| 도입 | 2025년 1월 |
| 핵심 | 추천 도서를 **신청 없이 자동 구비**, 도착 알림만 발송 |
| 결과 | 6개월 만에 이용률 38% → **71%** |
| 비용 | 월 예산 상한제(권당 상한 3만 원)로 통제 |

1. 학습 시간 절감 — 자료 탐색 시간 인당 월 1.5시간 절감
2. 이직률 개선 — 복지 만족도 항목 +12%p
   근거: 2025년 하반기 사내 설문(N=340)
